# 参考图 1:1 复刻门禁

当用户要求“必须和参考图一比一”时，不能只做同类重绘。每次复刻必须满足：

1. **画布一致**：保留参考图宽高比与主体非白区域在画布中的归一化包围盒。
2. **图元一致**：对象数量、节点类型、箭头数量、线段/虚线/圆/圆柱/弹簧阻尼器数量一致。
3. **语义文字一致**：标签逐字核对，不擅自替换变量；模糊标签先标记待确认，不能猜成新模型。
4. **位置一致**：关键点按参考图像素坐标归一化后映射到固定矢量画布；禁止自动紧边界导致主体被放大。
5. **比例一致**：物体宽高、对象间距、箭头长度、圆半径、坐标轴长度按参考图比例复刻。
6. **层级一致**：背景坐标轴→辅助轨迹→实体→关键视线/受力→强调层→文字，遮挡顺序一致。
7. **风格一致**：参考图如果是细灰线、小字号、低饱和色，不得擅自做成粗线、大字、高饱和“美化版”。
8. **解析几何**：切线、交点、视线束、圆柱中心轴等必须由坐标计算，不可凭眼摆放。
9. **对照板验收**：必须生成 REFERENCE / CURRENT 并排图；视觉审查明确相似度与差异，再迭代。
10. **交付格式**：保留结构化 JSON、可编辑源文件（TEX/PY/VSDX）及 PDF/SVG；PDF 必须是真矢量。
11. **禁止字体压缩**：导入 Python/TikZ SVG 到 Visio 时，必须读取 SVG 根节点的 `width/height` 或 `viewBox` 作为源纵横比，不能采用 Visio 导入后的边界比例。
12. **等比合成门禁**：每个导入面板均输出 `*.panel_metrics.json`，记录源比例、实际比例及形变率；`aspect_distortion > 0.002`（0.2%）立即判定失败，不得交付。独立特色图还要记录目标/实际宽高，`width_size_error`、`height_size_error` 任一超过 0.002 同样失败；仅比例正确但整体尺寸错误不合格。
13. **Visio 缩放顺序**：先按源比例计算目标宽高，再临时解除 `LockAspect` 精确写入两轴，最后重新锁定；禁止按版面框宽高直接拉伸。
14. **视觉复审**：分别检查 TikZ 中文/公式、Python 数据图坐标文字和 Visio 原生标题，确认不存在横向压扁或纵向拉伸。

目标门槛：结构化语义 100%，主要像素构图相似度 ≥ 90%；混合图面板纵横比形变率 ≤ 0.2%。达不到时不得称为最终版。
