# 高教杯优秀论文 MCP 绘图质量标准（持续优化基线）

依据 `高教杯优秀论文` 50 篇、760 条正式图号普查建立。目标不是机械模仿单图，而是让每张图承担明确的模型解释、求解、结果或验证职责。

## 1. 分工

| 绘图路线 | 主要职责 | 必须交付 |
|---|---|---|
| Visio（MCP） | 流程图、问题关系图、技术路线图、模型结构图 | `.vsdx + .pdf + .svg + .png + .json` |
| Python 代码（非 MCP，matplotlib） | 曲线、轨迹、空间布设、三维曲面、热力/等值场、仿真与收敛图 | `.py 绘图脚本 + .json + .pdf + .svg + .png` |
| TikZ（MCP） | 精确二维几何、公式关系、角度、尺寸与坐标标注 | `.tex + .json + .pdf + .svg` |

## 2. 统一视觉基线

- 白底；数据图可使用深蓝与橙色，流程图固定为白节点、深灰蓝线，仅阶段虚线框可使用克制蓝色。
- 流程图中文默认宋体，数据图中文默认微软雅黑；数学变量保持斜体；禁止出现未渲染的 `$...$`。
- 正文单栏/通栏适配宽度优先按 15.5 cm 设计。
- 图内标题可选；正式入论文时优先由图注承担标题职责。
- 主线 0.8–1.4 pt；箭头、坐标、标记缩小后仍清晰。
- PDF/SVG 必须为真矢量；PDF 页面不得仅嵌一张位图。
- 图内文字、线、标注不得贴边、裁切、压线或互相覆盖。
- 黑白打印仍需可辨：曲线同时用颜色、线型、标记形状区分。

## 3. 内容职责

- A 题优先：几何/物理机理图 → 动态响应/空间结果 → 优化与敏感性。
- B 题优先：数据诊断/空间路线 → 决策与算法框架 → 结果比较与验证。
- 流程图必须同时满足两点：存在非平凡分支、循环、判停、回退或模块依赖；短文、公式和表格又不足以让评委快速重建这条关系。步骤数、单个判断或目标奖项都不单独触发流程图。
- 判断节点必须标注“是/否”，回退路径必须指向真正发生变量更新的节点。
- 热力图只用于二维矩阵或空间场；一维关系禁止伪装成热力图。
- 数值图必须由数据生成，禁止在 Visio 中手工移动数据点。

## 4. 质量门禁

每张核心图进入论文前必须通过：

1. **结构**：图型选择与问题职责一致；无装饰性图。
2. **逻辑**：节点、箭头、变量、单位、分支和闭环正确。
3. **版式**：无裁切、重叠、压字、长线穿框、悬空节点。
4. **数值**：数据与模型输出一致；曲线不靠平滑掩盖原始结果。
5. **可读**：缩放至论文实际版心仍可读；灰度打印可区分。
6. **矢量**：PDF/SVG 可提取文字或路径，页面内无整图位图。
7. **可编辑**：保留 `.vsdx/.m/.tex` 和结构化 `.json`。
8. **复现**：同一 spec 重跑可得到相同结果。

## 5. 持续优化循环

`生成结构化 spec → MCP 输出源文件和矢量图 → 自动检查文件/页数/矢量性 → PNG 视觉审查 → 修正规范或服务器 → 重跑基准图`

当前基准图默认存放在 `figure_mcp/benchmark_outputs/`。

后续遇到新的优秀论文图型，优先扩展结构化 schema 和质量门禁，不通过鼠标模拟堆一次性操作。

## 6. 系统级高级构图能力

- TikZ `detail_inset`：局部放大必须由同一结构化 spec 内的原生几何图元重新绘制，ROI、双引线、
  放大框、切向/法向/角弧与标签均为矢量对象；禁止截屏裁块、公式贴图和白底覆盖。
- Visio `visual_preset: cumcm-classic-orthogonal`：冻结白底、白节点、宋体、标准流程形、正交细实线，
  自动在横向主链、纵向分支、分层依赖、目标—约束汇合、阶段分组与机理辅助版型之间选择。
  不再逐图确认风格；创新来自本题特有的信息结构，而不是焦点卡片、异常色或装饰徽标。
- 两项能力都必须在 A 类几何、B 类决策和通用算法三个跨题型 benchmark 中验证，不得以单题样图
  证明系统能力。
