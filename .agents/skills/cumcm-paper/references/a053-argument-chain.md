# A053 思路链结构锚点

本文件冻结 A053《基于目标优化的板凳龙形态调节》中可迁移的论证结构，不冻结其对象、模型、
符号、公式、算法、数值、标题、图表或句子。当前赛题必须先独立完成题意拆解、变量定义、候选
模型比较和求解，再按本文件检查论证是否缺环；不得因为 A053 使用过某种方法而选择同一种方法。

## 1. 全文级思路链

A053 的可迁移价值不在“每问都写得长”，而在于先求稳一个可复用的基础状态，再让后问只增加
题面新增的机制：

1. 先由对象的几何、物理或数据关系建立基础状态映射，并给出可复算的数值求解；
2. 遇到临界或可行性问题，先缩小可能失效的对象和范围，再建立判据并定位首次事件；
3. 遇到边界优化问题，把上一问的判据直接变成约束，先说明目标和决策变量，再做粗细结合搜索；
4. 遇到复合路径或分段过程，先拆分不能混写的子任务，分别求出结构参数和状态递推，再合并结果；
5. 遇到能力上限问题，继承前问的状态映射，把上限写成显式约束下的最大化，并检查活跃约束、
   邻域或独立复算；
6. 每问末尾把结果、可信证据和题面要求对齐，后问开头明确继承的状态、参数、可行域或约束。

这条链只按当前题目的真实结构取用。若题面不存在临界、优化、复合路径或能力上限，不得为了
对齐 A053 虚构相应环节。

## 2. 五类可迁移的逐问闭合

| 问题角色 | 冻结的功能推进 |
|---|---|
| 基础状态问 | 对象关系 → 状态方程或递推 → 数值离散 → 结果读数 → 趋势、误差或敏感性 |
| 临界可行问 | 可能失效对象/范围 → 边界构造 → 判定准则 → 首次事件搜索 → 临界前后复核 |
| 边界优化问 | 等价转化 → 决策变量与目标 → 继承判据形成约束 → 粗细搜索 → 边界与邻域检查 |
| 复合过程问 | 子任务拆分 → 共享关系 → 结构参数优化 → 分段状态递推 → 合并结果与异常解释 |
| 能力上限问 | 继承状态映射 → 最大化目标 → 硬约束 → 适配的搜索 → 活跃约束与独立核验 |

`question_architecture.chain_type` 应按功能选择，不按题号套用；每问的
`argument_plan.adaptation_basis` 必须说明当前题为什么采用该链，以及删去了哪些不适用环节。

## 3. 写前必须冻结的内容

正文起草前，每一问必须已经具备：

- 有题目对象的具体小节标题树，而不是“模型建立—结果分析—模型检验”通用框架；
- 从定义、基本规律或数据事实到最终模型的推导路径；
- 与题面每项要求对应的结果命题，以及结果需要解释的机理、趋势或决策影响；
- 独立检验和失效边界，其中检验对象、指标、阈值或判断条件已经明确；
- 每个命题最适合的表达载体。载体可为文字、公式、表或图，不设数量配额；同一命题可使用多图，
  但每幅图必须承担不同或互补的证据职责，并在正文中得到解释。

任一项缺失时不得开始成文。这样得到的篇幅来自完整论证，而不是编译后按页数补字、补图或拆公式。

## 4. 问题分析的抽取规则

问题分析只从完整思路链中抽取四类信息：决定路线的对象事实或约束冲突、关键数学转化、实际
求解链、传给后问的对象。它不复制后文的完整推导、参数表或结果，也不把这四类职责机械写成
等长四段。段首从本题对象、条件、关系或异常进入，避免跨问复用“为了求解……采用……”和
“首先—然后—最后”骨架。

## 5. 复制与盲测边界

- A053 只作结构锚点，任何连续原句、专属标题、符号、数值和图形均不得进入新稿；
- 当前题与 A053 同题或高度相似时，独立模型、变量和结果冻结前不得读取其正文；
- 冻结后只能做漏环和叙事校准，不能用其答案修正本队结果；
- 成稿仍须通过相似度审计和证据矩阵核对。
