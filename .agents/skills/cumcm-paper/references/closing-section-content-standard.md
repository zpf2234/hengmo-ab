# 评价、引用与附录内容标准

本标准来自本地 50 篇优秀论文的评价推广、参考文献和附录普查。统计用于识别职责，不用于凑数量。

## 评价、改进与推广

40/50 有评价标题，28/50 有改进或推广标题，独立结论章仅 5/50。坐标切分的 37 篇评价段中，
73.0% 出现优点，81.1% 出现局限，56.8% 出现改进，56.8% 出现推广，83.8% 出现证据信号；
近似字符量 Q1 / 中位数 / Q3 为 306 / 425 / 735。

每项优点采用“模型结构—已展示证据—带来的可靠性或效率”；每项局限采用“触发条件—受影响结论—
当前证据范围”；每项改进采用“薄弱环节—新增信息或方法—可验证变化”；推广说明保留机制、需要
重估的参数和新增约束。没有新增职责时合并成一节，不设重复摘要的结论章。

低于 Q1 时检查是否只有口号；高于 Q3 时检查是否重复逐问结果、堆未来工作或泛泛宣传。

## 参考文献

50/50 有参考文献，条目数 Q1 / 中位数 / Q3 约为 5 / 7 / 13；42/50 出现正文编号引用，12/50 含
DOI 或 URL。数量不是质量目标。

只收录实际阅读且在正文承担明确作用的真实来源。逐条核对作者、题名、年份、载体、卷期页码和
DOI/URL；每个条目至少对应一个正文主张，每个外部公式、参数、数据或算法来源都有条目。
优先原始论文、标准、官方数据说明和权威教材，删除不可核实或只为增数的来源。

## 附录

50/50 有附录或等价复现材料；附录页数 Q1 / 中位数 / Q3 约为 10 / 16.5 / 28。页数由完整代码和
复现需求自然形成，不追求中位数。

按以下顺序组织：

1. 支撑材料清单及用途；
2. 按问题或功能模块排列的实际运行代码；
3. 真实环境、依赖版本、输入输出约定与复现命令；
4. 正文放不下但核查结论所需的补充推导、表格或诊断。

正文必须独立给出模型、关键推导和答案，附录不能代替论证。代码必须完整、可搜索、可运行，无省略号、
个人绝对路径、身份信息、第三方作者痕迹和模糊截图。不得用原始数据、重复代码、终端日志或自动表格灌页。
