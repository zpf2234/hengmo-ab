# CUMCM 参考文献

先读 [../cumcm-paper/references/section-chain-contract.md](../cumcm-paper/references/section-chain-contract.md) 与
[../cumcm/references/full-paper-census.md](../cumcm/references/full-paper-census.md)，并读取
[../cumcm-paper/references/closing-section-content-standard.md](../cumcm-paper/references/closing-section-content-standard.md)。

## 50 篇普查校准

50/50 有参考文献标题。条目数 Q1/中位/Q3 约 5/7/13，最大 40 条。
正文编号引用信号 42/50，DOI 或 URL 仅 12/50。
数量不是质量指标：普查显示优秀论文中位数仅 7 条，但每条都承担明确的正文作用。

## 来源原则

- 只列实际阅读、可以核实且在正文承担明确作用的来源；
- 优先原始论文、标准、官方数据说明和权威教材；
- 方法常识不需要堆引文，但外部公式、参数、算法或数据必须给出处；
- 不用 50 篇优秀论文作为同题答案来源，也不复制其引文表。
- AI 工具不列入参考文献。2026 年在参考文献之前另设“AI 工具使用声明”，按实际使用如实填写；
  使用详情放入支撑材料压缩包内的 `AI工具使用详情.pdf`。

## 优秀论文规范表达范本与防 AI 味指南（基于 50 篇语料）

50 篇优秀论文参考文献条目数中位数为 7 条（Q1–Q3: 5–13 条）。参考文献不在于数量多，而在于**真实、规范且与正文精确对位**。

### ❌ AI 味典型表达 vs ✅ 50 篇优秀论文规范表述

| 维度 | ❌ AI 味套路表达 | ✅ 优秀论文规范引用表述（50 篇对标） |
|---|---|---|
| **正文引用**| “参考了大量的相关文献[1-10]，我们发现龙格库塔法是解决此类微分方程的最好方法。” | “波浪能装置的垂荡运动激励力计算采用线性水动力理论[1]。” *(在具体理论/参数来源处精准上标引用)* |
| **文末描述**| 编造假 DOI、缺少卷期页码、格式混乱 | `[1] 威廉姆斯. 海洋波浪能俘获力学原理[M]. 北京: 海洋出版社, 2018: 45-52.` *(符合 GB/T 7714 规范)* |
| **虚假引用**| 把题目给的附件或自建的脚本写进参考文献 | 仅收录正式出版物、权威标准、学术期刊及官方数据集。 |

### 规范写作纪律

1. **正文引用精准落脚**：放在具体公式、参数、模型理论或数据的首次出现位置，严禁在段末批量堆砌 `[1-8]`。
2. **严禁在正文出现自我解释**：“参考了大量文献”、“引用了文献[1]证明本文正确”。

## 引用位置策略

按正文作用确定引用位置，不在文末集中补引：

| 正文作用 | 引用位置 | 示例 |
|---------|---------|------|
| 模型理论来源 | 模型建立章首次使用该理论处 | "基于 Navier-Stokes 方程[1]" |
| 参数取值来源 | 参数使用处或参数表注 | "取 $\mu = 0.3$[2]" |
| 算法来源 | 方法选择或求解章 | "采用遗传算法[3]求解" |
| 数据来源 | 数据描述或问题分析 | "根据 XX 统计年鉴[4]" |
| 背景事实 | 问题重述或分析中的背景句 | "波浪能占海洋能的 XX%[5]" |
| 评价标准 | 评价章 | "参照 XX 指标体系[6]" |

## 引用密度校准

以 50 篇语料中位数 7 条为参考，按正文实际需求分配：

- 背景与问题：1–2 条（仅在题目背景需要可溯源事实时）
- 模型/方法理论：3–8 条（核心公式、算法、评价框架的原始出处）
- 数据/参数来源：1–3 条（外部数据源、物理常数、工程参数）
- 算法实现：1–3 条（非标准算法或改进方法的原始文献）

总量由实际使用决定，不为达到中位数凑引文，也不因低于 Q1 而忽视必要出处。

## 核验操作化

建立引用双向表，逐条执行：

```text
正文主张 → 引用位置 → 文献条目 → 核验状态
────────────────────────────────────────────
"Navier-Stokes方程" → §5.1第2段 → [1]Landau 1987 → ✓作者/题名/年份
"阻尼系数取0.3"     → §5.2表3注  → [2]GB/T XXXX → ✓标准号/年份
```

核验清单：
1. 为正文每个引用位置记录支持的具体主张。
2. 逐条核对作者、题名、年份、期刊或出版社、卷期页码、DOI/URL。
3. 检查每个文末条目至少被引用一次，每个外部主张都有对应条目。
4. 删除无法核实、只为增加数量或与正文无关的来源。
5. 按当年官方模板统一编号、标点与中英文格式。

## 格式示例（GB/T 7714 近似）

```text
期刊：[1] 作者. 题名[J]. 期刊名, 年, 卷(期): 页码.
图书：[2] 作者. 书名[M]. 出版地: 出版社, 年: 页码.
标准：[3] 标准号, 标准名称[S]. 年.
网络：[4] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

当年官方模板有独立格式要求时以官方为准。

## 禁写

- 编造 DOI、作者、页码或访问日期；
- 把搜索结果摘要当作已阅读文献；
- 引用题目附件时伪造外部来源；
- 在正文用"参考了大量文献"等元叙事；
- 以文献数量衡量质量。

## 门禁

建立引用双向表并写 `gates/references.json`，至少检查 `citation_to_entry`、`entry_to_citation`、
`metadata_verified`、`claim_supported`、`no_padding_reference`、`ai_statement_before_references`
和 `ai_tool_not_in_references`。无法核实的条目必须删除或补证，
不得标记通过。通过后由 `cumcm-paper` 继续执行
[../cumcm-appendix/STAGE.md](../cumcm-appendix/STAGE.md)。
