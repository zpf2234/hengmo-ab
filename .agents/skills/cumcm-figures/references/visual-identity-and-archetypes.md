# CUMCM A/B 全局视觉身份与特色图原型目录

## 1. 视觉身份不是统一配色

全局视觉身份用于让读者跨章节快速识别“普通证据—关键边界—最终结论”，不能覆盖变量本身的科学语义。默认身份 `cumcm-global-v1`：

| 语义层 | 默认样式 | 约束 |
|---|---|---|
| 结构/基线 | 深灰 `#30343B`、细实线/虚线 | 不与最优方案争夺视觉重心 |
| 主变量/主路径 | 冷蓝 `#355C7D` | 同一变量全文一致 |
| 辅助状态/可行域 | 青绿 `#2A9D8F` | 只能表示明确状态，不作装饰底色 |
| 临界/最终结论 | 橙红 `#D98254` | 每图至多一个主要结论色 |
| 不确定区间 | 同色低透明带或灰纹理 | 必须有置信度/口径 |

白底、微软雅黑、最终刻度/图例不低于 8 pt、线宽两级、颜色并非唯一区分手段。图题置于图外。视觉身份必须在 `figure-registry.json.visual_identity` 登记；`semantic_consistency_pass=true` 只可由全文变量—样式对照复核后填写。

## 2. 特色图合格判据

特色主视觉图必须同时具备：

1. **核心命题**：一条不可替代的 `core_claim`，且绑定 `claim_ids`；
2. **十秒结论**：`ten_second_takeaway` 能读出对象、变化/边界和答案；
3. **阅读链**：`read_order` 是机制/状态/结论等语义步骤，而非“左—中—右”；
4. **数据联动**：`data_linkage` 指明源字段及跨面板/图元的因果或读数联动；
5. **新增职责**：图确实连接原本分散的证据，不是仅换配色、加图标或把普通图并排；
6. **双尺度通过**：缩略图轮廓清楚，最终论文页面中文字、图例、标注和图题均可读。

复合不是必要条件。单一参数相图、时空轨迹带或策略景观只要完整承担上述职责即可；单一后端能完成时不强制拼图或混合软件。

## 3. A 类 signature archetype catalog

| registry 值 | 适用证据 | 推荐阅读链 | 必须防止 |
|---|---|---|---|
| `a_mechanism_result` | 方程/几何触发结果变化 | 机制定义 → 临界事件 → 结果闭合 | 机理示意与结果曲线互不相干 |
| `a_critical_configuration` | 首次碰撞、遮挡、极值构型 | 全局构型 → 局部放大 → 约束余量 | 仅画好看的三维场景 |
| `a_spatiotemporal_evolution` | 轨迹、速度、状态共享时间/弧长轴 | 轨迹轮廓 → 关键事件 → 状态响应 | 不同横轴强行对齐 |
| `a_phase_map` | 双参数可行域、稳定域、最优边界 | 参数域 → 边界/临界线 → 当前解与鲁棒余量 | 用热力图替代一维序列 |
| `a_convergence_closure` | 多精度、独立算法、解析特例 | 分辨率 → 交叉闭合 → 报告精度 | 只画一次收敛曲线即称精度充分 |

A 类特色图至少一张应满足 `mechanism_to_result=true`，但若题目确无机理结构，可在全局豁免中说明，不得伪造机理面板。

## 4. B 类 signature archetype catalog

| registry 值 | 适用证据 | 推荐阅读链 | 必须防止 |
|---|---|---|---|
| `b_strategy_landscape` | 双参数下最优动作区、价值等高线 | 情景位置 → 策略区 → 切换边界/价值 | 颜色区没有可复算策略标签 |
| `b_strategy_fingerprint` | 多场景动作矩阵与收益/间隙 | 场景 → 动作组合 → 收益与稳健性 | 普通热力表仅换配色 |
| `b_uncertainty_decision` | 样本量/置信区间驱动策略切换 | 不确定性收缩 → 阈值穿越 → 决策/价值恢复 | 三张折线并排却没有共同事件 |
| `b_probability_flow` | 真实可计算的状态转移、再生次数 | 状态 → 概率流 → 吸收/收益 | 桑基线宽凭视觉估计 |
| `b_pareto_strategy_map` | 全策略、利润—风险—动作代价 | 可行集 → Pareto 边界 → 推荐点与近优间隙 | 只展示胜者、隐藏全部候选 |

`cross_type_uncertainty_decision` 适用于 A/B 均可能出现的“参数/测量不确定性改变控制或选择”的联动图。

## 5. 规划方法

在标题树与证据矩阵稳定后、普通图批量生成前，复制 `templates/signature-figure-plan.md`：

1. 为每个核心 `claim_id` 评估是否需要特色图；
2. 选择一个原型，不因题号套用；
3. 画出语义阅读链和跨图元 linkage；
4. 检查能否删除/合并重复常规图，但保留必要诊断证据；
5. 先生成缩略预览，再按最终论文宽度复核；
6. 把 registry 字段、渲染和 provenance 一起冻结。

## 6. 有理由豁免

国一模式至少应有一张合格特色图；只有以下情况可豁免：题目证据本质上单一、复合表达会重复同一数据，或图会歪曲维度/因果。豁免必须在 `signature_policy.exemption` 记录不少于 12 字的具体理由、关联 `claim_id`/审查证据、独立审查者和 `APPROVED`。不得使用“时间不足”“不想拼图”“普通图够好”等理由。豁免只免除特色图数量，不免除科学、provenance、逐图正文解读、最终页面和其他视觉门禁。
