# CUMCM 模型竞技场

## 何时使用

每个会实质改变最终答案的关键问题必须调用。基本机理唯一时，把不同离散、解析特例或独立实现作为挑战者；不得为满足数量伪造方法对比。

## 题型路由

候选生成前完整读取
[../cumcm/references/ab-model-algorithm-routing.md](../cumcm/references/ab-model-algorithm-routing.md)，并运行：

```bash
python .agents/skills/cumcm-model-tournament/scripts/validate_ab_model_catalog.py
```

先按研究对象、状态演化、观测结构、决策变量、约束、不确定性和交付识别问题签名，再选择一个
主路由和必要的辅助路由。题号字母只能说明语料范围，不能作为路由键。目录提供的是候选边界，
不是算法清单；实际候选必须写出模型方程、参数来源、求解器契约和可执行验证。
调度、分配、路径、选址、资源、连续设计、鲁棒或多目标优化还须完整读取
[references/optimization-solver-contract.md](references/optimization-solver-contract.md)，先强化模型和
构造可行基线，再选择或调优求解器。

## 竞技协议

试算前写 `求解/模型竞技场.json`，冻结：

- 问题签名、主/辅助路由 ID 及不适用路线；
- 统一题意口径、训练/验证数据和约束；
- 透明基线、主候选、异构挑战、fallback 的角色；
- 硬淘汰条件和评分指标；
- 数值容差、随机种子、时间预算；
- 每个候选的结论等级上限，以及升级所需证据；
- 何时只能报告估计、最佳已知、近优、区间或并列候选。

候选依次通过题意、单位/量纲、定义域、约束、可识别性、数据泄漏和可复现性硬门槛。存活候选再比较独立验证、稳健性、答案质量、复杂度、计算代价和可解释性。优化问题增加可行性、界/gap、小实例精确解或扩大邻域证据；逆问题增加合成回收、目标剖面、多初值和参数相关性；预测问题使用严格留出或时间外推。

候选按以下最低组合建立：

1. **透明基线**：暴露量纲、数量级、方向与约束错误；
2. **主候选**：最贴合题面机理、数据结构与决策空间；
3. **异构挑战**：主要误差机制不同，不是同一代码换名称或随机种子；
4. **fallback**：不可识别、不收敛或超时后仍可交付的保守路线。

若问题基本规律唯一，允许不伪造第二套模型，但必须以解析特例、不同离散、不同估计器或独立实现
挑战主结果。候选差异小于数值或抽样不确定性时，保留区间或并列候选。

## 最小充分方法原则

先冻结题面闭环、精度、约束、稳健性、运行时间和可解释性门槛，再按“能完整通过门槛的最低
复杂度”选主方法：

1. 解析关系、直接计算、完备枚举、动态规划、经典统计或确定性优化能够完整解决时，优先选用；
2. 简单方法全部硬门槛通过且答案差异小于数值/抽样不确定性时，直接保留简单方法为主模型；
3. 只有简单路线在预先声明的指标上失败，而复杂路线带来可复核的实质改善时，才允许升级；
4. 机器学习、神经网络、遗传算法、粒子群、差分进化等没有“智能算法加分”。采用者承担额外
   证明责任：数据/搜索空间确有需要、验证增益稳定、参数与停止条件完整、结论强度不过界；
5. 为模型选择而伪造复杂挑战、把同一算法换名称，或以“更先进”替代证据，均直接淘汰。

在 `求解/模型竞技场.json` 记录 `minimum_sufficient_decision`：简单候选是否达到门槛、
复杂候选解决了哪一项具体失败、增益是否超过不确定性、最终为何选择或拒绝升级。

## 结论认证

- “全局最优”只由完备枚举、数学证明、凸/对偶证书或分支定界 gap 支撑；
- 局部求解器和元启发式默认最多支持“最佳已知/近优候选”，多初值稳定不能升级为全局证明；
- 自适应 Monte Carlo 或机会约束若比较多个候选，必须有同时误差控制、可选停时有效规则和
  最终独立确认；只有逐点区间时最多报告估计结果；
- 参数不可识别、边界解释未隔离或搜索空间被未声明缩小时，先淘汰或降低结论，不进入软评分。

## 创新审计

写 `求解/创新贡献表.md`，只保留能改变结论、精度、验证或解释的贡献。换算法名称、堆模型、调配色、增加无效指标不算创新。每条贡献绑定公式、结果差异、验证和适用边界。

## 输出与门禁

在 `求解/候选淘汰记录.md` 逐项记录路由 ID、执行状态、淘汰证据、保留原因和结论等级。
主模型必须经至少一个不同主要误差机制的挑战；候选差异不超过数值/抽样不确定性时不得制造
唯一胜者。

完成条件：目录校验通过；比较协议先于结果冻结；所有声称执行的候选有运行产物；主模型选择
可由证据复核；结论强度不超过证据等级；失败路线仍保留足够的挑战证据。否则
`BLOCK_MODEL_SELECTION`。
