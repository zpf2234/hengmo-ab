# CUMCM 优化模型与求解器契约

本规则用于调度、分配、路径、选址、资源、连续设计、鲁棒与多目标分问，保留原运筹优化技能中
影响竞赛答案质量的路线与排障规则，不保留独立技能触发。

## 1. 先识别结构

| 主导结构 | 首选基线/主路线 |
|---|---|
| 连续资源、配比、流量平衡 | 解析/KKT、LP、QP、SOCP 或凸优化 |
| 开关、固定费用、指派、覆盖 | LP 松弛 + MILP/MIQP |
| 大量逻辑、时序、互斥、日历 | 完备小例 + CP/CP-SAT |
| 纯图或弱耦合图 | 最短路、流、匹配、树等专用算法 |
| 平滑连续非线性 | 多初值局部 NLP；可证明凸时保留全局证书 |
| 场景、区间、风险 | 标称基线 + 鲁棒/随机/机会约束 |
| 块结构或列空间巨大 | 松弛界 + 分解、列生成或拉格朗日路线 |
| 精确法超时且需可行方案 | 问题特定启发式或 matheuristic，结论降为最佳已知 |

不因熟悉某工具强行套模型。先给出变量、目标、硬/软约束、粒度、运行预算和答案形式。

## 2. 调参前先强化模型

按顺序检查：

1. 收紧变量上下界并统一尺度；
2. 消除固定变量、重复约束、对称变量和无效候选；
3. 用指示约束、流平衡、集合划分或有效不等式替代宽松 big-M；
4. 先用规则、图算法或历史方案产生可行 warm start；
5. 再调整 presolve、cuts、heuristics、并行、time limit 与 gap。

求解慢首先是模型诊断问题。松弛过弱、对称性、错误尺度或不可行约束未排除时，不得只换求解器。

## 3. 求解器路由

- 图算法/小规模枚举：优先独立实现，作为可手工核对基线。
- LP/QP/MIP：开源 HiGHS/CBC/SCIP 可作基线；记录状态、incumbent、best bound、gap 和容差。
- 逻辑排程：CP-SAT；记录时间限制、相对 gap、随机种子、worker 数和可行性复核。
- 平滑 NLP/标定：SLSQP、trust-constr、L-BFGS-B 或相应求解器；记录初值、bounds、梯度检查、
  约束残差和多初值结果。
- 商业求解器只在变量域、松弛、warm start 和合理参数均已处理，而开源路线仍无法满足精度或
  时间预算时升级；算法品牌本身没有加分。

## 4. 元启发式与混合方法

精确/确定性路线超时、黑箱评价或题目结构支持专用搜索时，可探索元启发式与混合候选；
不要求先证明精确路线失败。按 [创新与组合规则](innovation-and-composition.md) 解释预期收益，
并与适用的确定性路线及原算法公平比较；基线已达标时，仍可凭有实际价值的加速、精度或
稳定性收益采用改进。按题目需要设计编码、可行性检查、修复器、增量评价和局部邻域，
不要机械配齐算子；关键子问题适合精确求解时保留该结构。

保存种群/温度/邻域、种子分布、无改进轮数或时间停止、局部精修、小实例精确校准和扩大搜索
范围结果。稳定多次运行不等于全局最优，默认结论上限为最佳已知。

## 5. 失败诊断

- 无可行解：先检查单位、上下界、互斥约束，逐类放松并定位最小冲突；
- 首个可行解太慢：加强 warm start、修复器和启发式，检查候选空间；
- incumbent 好但 bound 慢：强化松弛、对称破坏、分解或有效不等式；
- NLP 对初值敏感：检查尺度、可微性、约束资格、目标剖面和多解；
- 方案无法执行：从结果反向逐条复核全部硬约束和离散精度。

论文只按证据声明精确最优、认证近优或最佳已知，不把求解器 success 当作结论证书。
