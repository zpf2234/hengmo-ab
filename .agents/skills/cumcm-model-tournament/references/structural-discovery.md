# 新题关键数学结构查漏

每问生成候选时读取本文件。在算法选型前检查下列六类结构；只记录适用项的具体推理，不为每问凑六个模型。不适用项简述题目依据，未解决项标为待证。可合并进已有求解计划；仅要思路时不启动编码、数值竞技或论文流程。

| 检查方向 | 要问的问题 | 可审查的产出 |
|---|---|---|
| 解析关系 | 能否从守恒、几何、概率恒等式或约束求导直接联系输入与答案？ | 方程、变量含义、条件；指出仍需数值求解的部分 |
| 临界状态 | 首次、最大、最小、失效或策略切换发生在哪些边界？可能相切而不变号吗？ | 临界方程、事件候选、端点和内部极值检查范围 |
| 对称性 | 平移、旋转、置换、尺度变换是否保持目标及全部约束？ | 不变量、对称条件、可消除的冗余；边界或异质性破坏对称时的反例 |
| 单调性 | 参数变化能否保证可行域嵌套或目标单调？是否只在某个分支成立？ | 证明路径或待证命题；未证时保留扫描/分支检查，不直接二分 |
| 关键对象 | 是否由少数接触对、瓶颈工序、活跃约束或信息充分的状态决定答案？ | 对象筛选依据及未被筛选部分的排除证据，不能先猜关键对象再只验证它 |
| 等价简化 | 能否消元、无量纲化、重新参数化、分离尺度或压缩状态而保留所需答案？ | 原模型到简化模型的映射、解的恢复方式及适用域；近似简化另列误差 |

在 `求解/关键结构查漏.md` 或既有计划中逐问记录：题面触发线索 → 数学关系/待证命题 → 对候选路线的影响 → 证明、反例或小算例验证办法 → 已推导/待验证/不适用。不得以“考虑对称性、使用动态规划”等方法名代替关系；只有思路时，验证办法不写成验证完成。

先广泛探索不同结构，再按题意与可计算性缩小候选。常规路线与新视角并行考虑，不要求简单路线失败才探索改进；也不把结构简化自动称为创新。原理唯一时比较不同表示或独立实现，不伪造异构模型。

冻结主候选前做一次反向检查：从每项必答输出倒推所需关系，是否遗漏全过程约束、切换分支、极端对象或解析简化？若仍只有算法名、没有题面到方程的对应，返回候选生成；若关键命题未证明，保留一般模型或降低结论，不强行降维。

查漏表检查的是推理覆盖，不保证穷尽所有数学路线，也不证明已命中未知的官方思路。同题参考中的关键思想覆盖评估按历史题协议执行，不提前读取同题方法链。
