# CUMCM 评分共性画像（2018-2025 A/B 官方评阅材料提炼）

依据 2018-2025 年 A/B 题官方评阅要点、命题人讲评与期刊解析（16 题，见
`cumcm-blind-benchmark/assets/grading-standards/`）提炼的跨年评分共性。
本文件**不含任何题目的具体数值答案**，求解、写作、审查全程可读。
逐题评阅要点含答案数值，受盲测隔离纪律约束，见该库 README。

## 一、评阅制度事实

- 章程规定的四条主标准：**假设的合理性、建模的创造性、结果的正确性、文字表述的
  清晰程度**。
- 两级评阅：赛区评阅（比例内报送全国）→ 全国评阅。每篇至少 3 位评委独立评阅；
  初评单篇阅读时间约 5-10 分钟——摘要页决定第一印象。
- 全国组委会向各赛区下发**评阅要点**，但"仅供参考，各赛区评阅组应根据对题目的理解
  及学生的解答，自主地进行评阅"；赛区在此基础上制定可操作的评阅细则。
- 评阅总则（2018 年原文，导向跨年稳定）：
  - 鼓励"针对具体问题，分析问题、自主创新、建立模型，求解得到真实有效的结果"；
  - **不鼓励"非针对具体问题的数学方法堆积与罗列、通用模型和算法的简单拷贝"**；
  - **不鼓励"套路化、形式化、虚拟化的表面文章和没有实质内容的'语文+美术'类论文"**；
  - "建议在有条件的情况下，对参赛队提交的电子文件中的**程序和结果进行验证**"
    （2018B 更明确建议评委"编程验证调度方案（结果）的可行性"）。
- 有突出创新点的论文可由评阅组长签署意见破格报送全国（每赛区每题每年至多一篇）。
- 命题人讲评的通用建议（2020 年原文，可视为评阅价值观）："重视基本理论和基本方法
  的学习""注重求解和计算机应用能力，走完解决问题的'最后一公里'""严守结果的正确性
  和逻辑的合理性"。

## 二、评阅要点的结构共性（如何按评阅视角组织每一问）

历年评阅要点对每一问的表述结构稳定，可作为逐问自查框架：

1. **必备交付清单**（"应给出 / 必须明确给出"）：模型 + 算法 + 结果三件套；
   要求的中间量（如函数关系、参数反演值、指定时刻/位置的数值、结果文件）缺一即
   不完整。
2. **方法宽容度**（"可用以下方法（并不局限于此）"）：路线不唯一，机理分析、
   解析求解、数值仿真通常并列认可；但**仿真必须附可靠性分析**。
3. **判据句**：加分用"……应予以鼓励 / 值得鼓励 / 模型更好"；扣分用"……则不是好的
   做法 / 不是好的结果 / 所建立的模型是不完整的"。

## 三、跨年扣分模式（高频雷区清单，fail-closed 自查）

### 模型完整性

- 只有方程、没有定解条件（初始/边界/交界面条件），"所建立的模型是不完整的"；
- 该用瞬态/动态模型时只建稳态模型（导致关键参数无法反演）；
- 力/力矩、成本/收益等构成清单缺项（要点常逐项点名应包含的项）；
- 只针对题给数值硬编码建模，不具通用性（应先给一般模型的完整数学描述，再代入
  指定数值）；
- 方案未覆盖问题设定的全部特征维度（如只处理不确定性而忽略实时性、只优化路线而
  忽略初始资源决策）——设定中的每个维度都须有对应机制，缺一即"缺少清晰的整体
  求解思路"。

### 方法与算法透明度

- **"不能笼统地说由软件计算得到"**——必须写明计算方法与步骤；
- 只报算法名不给具体算法描述与**超参数具体数值**（智能算法尤其如此）；
- 标准算法不加改造直接套用而忽略问题特性（如区间端点二义性、目标函数梯度为零
  导致伪收敛）；
- 解析法不检查适用条件直接套用（分离变量法"是有限制条件的"、积分变换法要求
  无界区域，有限区间初边值问题不满足）；
- 显式差分等条件稳定格式不检查稳定性条件；**待反演参数未知时稳定性条件无法事先
  验证，参数确定阶段"使用显式差分格式是不对的"，须用无条件稳定的隐式格式**，
  参数确定后的正演计算可再换回显式格式；
- 数学规划模型"有名无实"：决策变量未起纽带作用（目标函数和约束条件中缺少决策
  变量或存在未知变量、变量之间未建立正确联系）、逻辑关系与分段函数未转化成决策
  变量之间的函数关系、混淆数学（线性）规划和动态规划的概念和具体做法。

### 统计与数据处理

- 直接用某类函数（一次、二次等）拟合而**没有误差分析或检验**；
- 分布假设不明确（如小批量应超几何、大批量二项近似、大样本正态近似，直接用正态
  而不说明假设）；
- 数据预处理缺失：异常段照算、噪声不平滑、需要人工干预的处理流程（应全自动）；
- 反向同样扣分：把携带真实结构的数据点当异常点剔除而不评估影响（评阅要点会点名
  "必须考虑它们"）；
- 把"一致性"当"可靠性"：一致性差的结果肯定有问题，但一致性好不代表正确，
  可靠性需独立验证。

### 结果与验证

- 结果不满足题面的硬约束（可行性不等式、格式模板、指定输出文件）——可行性先于
  一切效率指标；
- 只报最优目标值，不给可复现的具体方案（逐条坐标、逐步决策、参数表）；
- 最优点落在数据/实验范围之外很远处（外推失控），"不是好的结果"；
- 多部件/多阶段贡献直接相加而忽略重叠（重复计数）；
- 用必要条件充当充分判据（如仅以左右面积差为零判定对称性——"是……必要条件，
  但不是充分条件"，应改用逐点偏差型度量）；
- 无模型检验：应加随机扰动考察稳定性、做重要参数敏感性分析。

### 简化与离散化

- 把连续体/刚体链简化为质点、把曲面面元简化为平面而不评估误差（误差不可控且
  依赖选取，几何过度简化可导致结果量级整体错误）；
- 把"未必成立的性质"当作必然成立的前提用于剪枝或简化（讲评会点名哪些直觉性质
  "未必成立"；正确做法见第四节占优准则——先证明再缩小空间）；
- 离散判别点集选取不当：点太少误差大，包含对判定无贡献的点白增计算；
- 定义不满足基本原则（如退化一致性、方向对称性——定义应在极限情形退回经典定义，
  且与计算方向无关）；
- 公式过于复杂：不便计算、不易理解、出错难查（评阅明确不喜欢）。

## 四、跨年加分模式（明确鼓励项）

- **解析解 + 稳定性分析**（数值解之外给出解析结构，"应予以鼓励"）；
- **给出模型的预测精度**（"应当鼓励"）；
- **占优准则**：先证明某些策略被支配，缩小搜索空间再求解（"值得鼓励"）；
- **两种完全不同的方法互证**同一结果，作为可靠性证明；
- 结果以统计量表达（均值 ± 标准差）而非单点值（多值结果时）；
- 完整**证明**关键结构性结论（而非引用规范或直觉断言）——历年完成者稀少，属
  区分度亮点；
- 多种策略/方案的**效果比较**（不止给一种可行方案）；
- 实验/抽样设计先给准则或模型，样本点兼顾空间均匀性与最优点覆盖；
- 在必选目标之外合理增加实际目标（如重量最轻、成本最低），"模型更好"；
- 多目标合成前先对各目标归一化（最值或极差归一）再加权，优于量纲不齐的直接相加
  （讲评把归一化式列为改进写法）；
- 嵌套高成本子模型（如 PDE 正演）的优化中，合理设计搜索使子模型求解次数有限并
  报告计算量（体现"最后一公里"的求解落地能力）；
- 开放问题上提出有原理依据的新方法（评阅要点常以"希望学生能……有所突破"结尾）。

## 五、A/B 题型差异

- **A 题（连续/机理型）**：核心是机理建模（ODE/PDE/几何/力学），评阅要点点名
  定解条件完整性、数值格式选择与稳定性、参数由附件数据反演（不得用文献常数替代，
  哪怕有国家标准支撑）、结果的物理解读。
- **B 题（数据/决策型）**：核心是统计与优化决策，评阅要点点名分布假设、指标定义
  （期望成本/收益等）、探索性分析 + 显著性检验、决策依据的量化呈现、仿真可靠性
  分析、实验设计方法论。

## 六、对技能链的映射

- **cumcm-solve**：拆解每问时按"必备交付清单 + 判据句"生成逐问验收标准；
  答案门禁自查第三、四节清单；算法说明必须达到"无软件黑箱"标准。
- **模型成文阶段 / cumcm-results-validation**：每问正文按"模型三件套 +
  检验"组织；扣分清单作为成文前 checklist。
- **cumcm-paper / cumcm-abstract/STAGE.md**：摘要按四条主标准 + 初评 5-10 分钟事实优化信息密度。
- **cumcm-review**：评分卡维度对齐四条主标准；审查者按第三节雷区逐条复核；
  复现抽查对应"评委验证程序"制度事实。
- **盲测阶段**：冻结后评估可加载同题逐题评阅要点作为评分口径
  （见该库 README 的隔离纪律）。
