# 优秀论文语料对标协议

优秀论文库用于校准质量，不用于复刻内容。开始求解前、论文成稿后各执行一次：

```bash
python .agents/skills/cumcm/scripts/benchmark_corpus.py --root .
python .agents/skills/cumcm/scripts/benchmark_corpus.py --root . --fail-on-similarity
```

默认从 `最终效果/高教杯优秀论文/` 读取 PDF，输出
`审查/优秀论文对标.json` 与 `审查/优秀论文对标.md`。
若该目录包含 `普查总索引与统一口径.md`，同时读取
[full-paper-census.md](full-paper-census.md)，优先使用已复核的全文脉络、分项 CSV 和
OCR/人工抽检边界，不再从旧版“标准模板”报告推导硬规则。
题名缺失或 PDF 无文本层时，先用 [corpus-map.json](corpus-map.json) 的显式映射选取同题语料；
未命中映射时再使用题名相似度。新增赛题或重命名语料后同步更新该映射。

## 使用边界

- 只学习结构特征：问题覆盖方式、论证链长度、图表职责、验证类型、正文与附录的比例。
- 不复制标题、摘要句式、段落、图注、专属模型链、参数、结果数值、代码或图形设计。
- 不因参考论文使用某算法就默认采用该算法；方法必须由题意、数据、约束和验证条件推出。
- 不把页数、图数、表数、公式数当成越多越好的目标。图数由待证明命题和不可替代证据职责决定；
  官方限制优先，语料统计只作区间参考。
- 同题论文只用于发现评委会追问什么，不作为答案来源。独立完成口径、推导、代码和数值验证。

## 邻近样本选择

优先选 3-5 篇：

1. 同赛道（A/B）且同类问题；
2. 数据结构或核心约束相近；
3. 方法路线不同，能暴露替代解释；
4. 年份分散，避免把单年排版习惯当成普遍规则。

若题目文件名无法判断 A/B，允许不分赛道并在对标报告中标记。

## 只提取这些特征

- 总页数及附录起始位置的近似值；
- 图、表编号数量；
- 是否出现误差、灵敏度、稳健性、收敛、残差或约束验证；
- 各问题是否都有“模型—求解—结果—验证—回答”；
- 摘要是否覆盖每问、关键数值与最终决策。

PDF 文本层异常时，把图表与验证统计标为不可用；需要时再做 OCR 或人工抽查，不把零计数当成论文真实特征。
同题语料全部无文本层时，相似度状态必须为 `WARN_REVIEW`，不得把“无可比文本”写成 `PASS`。只有补做 OCR/正式查重，或记录生成阶段隔离并由独立评审完成有限人工复核后，才能在回归汇总中解释性放行；报告必须保留“全文相似度未核验”的残余风险。

将观察写成当前项目的“质量预算”，例如“至少需要一次独立数值交叉验证”，不要写成
“必须复现参考论文的第 X 图或第 Y 个模型”。

## 原创性门槛

脚本先截取候选论文与语料第一页中“摘要—关键词”之间的正文，计算 8 字符 n-gram
containment；摘要达到预警线后，再对最高风险论文计算 12 字符全文 containment：

- 摘要 `<0.15` 且全文 `<0.10`：通常可接受；
- 摘要 `0.15-0.30` 或全文 `0.10-0.20`：人工检查模板化复述；
- 摘要 `>=0.30` 或全文 `>=0.20`：高风险，审查阶段直接 FAIL。

该指标只做预警，不能替代正式查重。对同题必要术语导致的局部重合，应人工核对连续句段；
任何非必要的长句重合都必须重写并重新组织论证。

### 门禁退出码与放行条件

`benchmark_corpus.py --fail-on-similarity` 是阶段 3 的原创性门禁。它把裁定写进
JSON 的 `originality_gate` 字段（`verdict` / `status` / `reasons` / `enforced`），并按裁定返回退出码：

| 退出码 | 裁定 | 含义 |
| --- | --- | --- |
| 0 | `PASS` | 相似度实测执行且落在可接受带 |
| 0 | `PASS_WITH_MANUAL_REVIEW` | 落在人工检查带，且有独立评审的 `pass` 记录 |
| 2 | `FAIL_HIGH_SIMILARITY` | 达到高风险线，人工记录一律不得放行 |
| 3 | `BLOCK_ORIGINALITY_UNPROVEN` | 原创性未被证明 |

退出码 3 覆盖的全部「未证明」状态：候选论文缺失、论文无可提取文本层、抽不到“摘要—关键词”正文、
对标语料为空、同题对照全部无可比文本、containment 落在人工检查带而无复核记录。这些状态过去一律返回 0，
即把「没测」读成「通过」，属本项目禁止的 fail-open。未加 `--fail-on-similarity` 时裁定照样写入报告但不阻断，
以便阶段 0 在论文尚不存在时完成语料校准。

人工复核记录写在 `审查/原创性人工复核.json`（独立文件，因为 `审查/优秀论文对标.json` 每次运行都会被重写）：

```json
{"pass": true, "reviewer": "<独立评审标识>", "scope": "<实际抽查范围>", "date": "<YYYY-MM-DD>"}
```

`pass` 为真但缺 `reviewer` 或 `scope` 的记录不构成放行依据；已归档但 `pass` 为假的记录按阻断处理。
该记录只对人工检查带有效，对 `FAIL_HIGH_SIMILARITY` 与各类 `NOT_RUN` 无效。
回归由 `scripts/selftest_similarity_gate.py` 用合成 PDF 固定上述 13 条判定，改动相似度逻辑后必须重跑。
