# A/B 题几何机理图路由与标注

## 数学标注背景

变量、公式、角度、点名、边长、坐标、概率与阈值全部使用透明背景。所有对象线、轨迹、轮廓、
尺寸线和箭头保持连续，不因标签而截断；文字放在线路周边。发生压线时通过移动标注、调整几何构图
或增加短引线解决，绝不使用白底遮罩。

本规则用于坐标关系、运动场景、空间可达、视线遮挡、碰撞、投影和几何判据图。几何图的
任务是解释模型对象与判据，不是复刻三维软件界面。

## 信息分层

1. **对象层**：目标、载体、障碍物、云团、区域和关键点。实体轮廓用基础几何表示。
2. **运动层**：轨迹、速度方向、投放段和状态变化。实线、虚线和箭头含义全文统一。
3. **判据层**：视线束、边界、半径、距离、投影轮廓和可行域。这一层必须对应正文公式。
4. **注释层**：对象名称、点名、轴名和短判据。注释不承担正文解释段落。

一幅图最多突出一个主要判据。场景关系与局部判据拥挤时拆成两图，不在一张图中同时塞入
完整三维场景、算法流程和结果曲线。

## 标签与锚点

- 除坐标轴字母、点名和对象内部数学符号外，所有文字必须登记对象锚点。标签移位时引线仍
  指向原对象，禁止依赖“放在附近就能看懂”。
- 引线端点必须由目标几何定义计算：线段与轨迹使用命名端点的插值坐标，圆或球使用圆心、
  半径与极角坐标，矩形、圆柱和节点使用轮廓锚点。禁止手填一个“接近目标”的末端坐标。
- 引线必须一端落在目标线段、轮廓或关键点上，另一端落在标签边界上；不得停在目标附近的
  空白处，不得越过目标后再折返，也不得连接到同类但错误的相邻线。
- 对象名称优先放在轮廓外部；轨迹名称放在轨迹外侧并用短引线指向线段；不把文字沿斜线
  旋转，也不把标签压在线、圆周、圆柱或箭头上。
- 主对象名和关键判据在论文成品中不低于 8.5 pt，普通标签优先 9--10.5 pt；次要轴名也必须可辨。
  先由论文插入比例反推源字号，不在导出后统一缩小补救。
- 点名、角度、概率、公式和普通标签使用透明背景。标签与线段冲突时移动标签、改变引线或调整构图，
  不使用白底无边框遮罩；画布可以为白色，但标注和承载数学符号的实体不建立白色覆盖层。
- 标签只写对象或量，如“起爆点 B”“目标视线束”“有效烟幕球”；定义、因果和结论放在
  图前后正文。

## Visio 坐标锁定

- Visio 文本形状写入字体和内容后，再次锁定位置与宽高，关闭自动适应，
  固定 `WordWrap`、四边距、垂直锚定和段落对齐。
- 使用实际字形包围盒审查位置。中文字体替换可能改变文本边界，创建时的名义
  高度不能作为最终坐标。
- 字体回退、字号、加粗、斜体、上下标和换行都会触发布局重审。文本框保持水平，不旋转。
- 导出前保存可编辑 `.vsdx`，再由同一 Visio 实例导出矢量 PDF/SVG，避免跨软件重排。

## 碰撞检查

生成器至少检查：

1. 实际字形包围盒位于画布内，并在文本框内保留 1--2 pt 安全距离；
2. 标签之间不重叠；
3. 标签字形不与轨迹、视线、边界、圆周、箭头或坐标轴相交；
4. 外置标签不覆盖无人机、圆柱、球体等实体轮廓；
5. 引线只连接自己的锚点与标签边界，不穿过第三个标签；
6. 逐条验证引线目标端点到所属几何对象的距离在绘图容差内，且到其他候选对象的距离更大；
7. 主对象、判据和标签在论文实际插入宽度下均完整可读。

任一碰撞失败时移动标签、改变引线方向或拆图；不得通过缩小字号、裁边或添加白底遮罩放行。

## 构图

- 主运动方向形成第一视觉轴，关键判据形成第二视觉中心；坐标轴作为参照，不抢夺视觉中心。
- 对象、轨迹和标签之间保留明显负空间。相邻标签尽量错开高度，避免形成一排说明文字。
- 线型不超过三种，强调色通常只用于核心边界或关键对象。红色适合标记有效球、危险边界等
  单一重点，不同时强调多个无关对象。
- 二维投影足以解释判据时不用伪三维；需要三维时确保遮挡关系、坐标方向和比例不误导。

最终还须执行 [diagram-layout.md](diagram-layout.md) 的固定画布、布局报告和整页渲染检查。
每条对象引线、轨迹引线、线束括号和轮廓标注另按
[diagram-connection-audit.md](diagram-connection-audit.md) 建立清单并逐条验收；只检查整图截图
或只验证端点坐标均不充分。
运动轨迹、下沉方向等有向线必须显示不被端点遮挡的方向标记；视线束、轮廓、半径和引线等
无向线不得误加箭头。线型与方向语义须在全文保持一致。
