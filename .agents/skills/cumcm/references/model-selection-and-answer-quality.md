# 无参考模型择优与答案充分性

本规则用于在不查看优秀论文模型链、数值结论或参考答案的条件下，提高模型适配度和最终答案
接近真实最优解的概率。文献只可用于核对物理定律、参数来源和通用算法，不得用于回填本题答案。

## 目录

1. 盲解边界
2. 候选路线生成
3. 硬淘汰与择优
4. 分题型答案强化
5. 答案充分性门禁
6. 论文中的模型选择
7. 证据结构
8. 回归与发布

## 1. 盲解边界

- 在最终答案、图表和验证冻结前，不读取同题优秀论文的模型名称、参数、结论、代码或图形。
- 允许读取题面、附件、官方规则、真实的学术或工程来源，以及不含同题答案的通用方法资料。
- 优秀论文只在冻结后由审查阶段用于覆盖率、验证强度和隐藏答案误差评估；若比较后修改模型或
  数值，该题不再计作盲测。
- 在 `求解/任务契约.json` 记录 `参考答案在求解期可见: false`；审查时核对时间顺序。

## 2. 候选路线生成

每问先建立最小候选组合，不按算法热度选择：

1. **基线**：最简单、可手算或可快速复算的路线，用于暴露单位、量级和方向错误；
2. **主候选**：最贴合题面机理、数据结构和决策空间的路线；
3. **异构挑战**：使用不同信息、目标或数值实现的路线，用于挑战主候选；
4. **fallback**：主候选不可识别、不可收敛或超时后仍能交付的保守答案。

通常保留 2--4 条真实可执行路线。若基本规律唯一确定模型，允许使用“唯一机理”模式，但仍须
提供不同离散、不同估计器或解析特例作为独立挑战，不得以“模型显然”免除验证。

候选路线必须在编码前写明：信息使用范围、关键假设、决策空间、待估参数、主要风险、淘汰条件
和预期验证。禁止试算后倒改判据迎合最高结果。

## 3. 硬淘汰与择优

### 3.1 先做硬淘汰

任一候选出现下列情况即淘汰，不参与加权评分：

- 违反题面、量纲、守恒、几何关系、概率公理或硬约束；
- 使用未来信息、标签泄漏、输出模板反哺输入或同题参考答案；
- 关键参数不可识别，或多个参数组合产生不可区分答案却未报告区间；
- 通过未声明的降阶缩小题面允许空间，且没有扩大邻域检查；
- 只能产生单次偶然结果，无法从原始数据复算；
- 没有可执行的独立验证或失败判据。

### 3.2 再按证据顺序择优

对通过硬门槛的候选按以下优先级判断，不用一个任意加权总分掩盖硬伤：

```text
题意与物理正确性
→ 独立验证表现
→ 稳健性与可识别性/最优性
→ 预测误差、拟合误差或目标函数
→ 模型复杂度与计算代价
```

模型更复杂只有在预先指定的验证指标上带来实质改善时才升级。主候选与挑战路线差异不超过
数值误差或抽样不确定性时，保留两者形成答案区间，不强行宣布唯一优胜者。

### 3.3 冻结选择记录

每问在 `metrics.json` 中保存 `模型选择`：

```json
{
  "模式": "候选比较",
  "候选": [
    {"名称": "路线A", "角色": "基线", "判定": "保留为验证", "证据": ["误差=..."]},
    {"名称": "路线B", "角色": "主候选", "判定": "选用", "证据": ["误差=...", "约束通过"]}
  ],
  "主模型": "路线B",
  "选择依据": ["独立验证误差更低", "参数扰动下结论不变"],
  "论文呈现": "简述"
}
```

`论文呈现` 取 `简述` 或 `不写`；选择 `不写` 时记录理由。候选比较的完整记录只留在内部证据包。

## 4. 分题型答案强化

### 4.1 机理与几何

- 用量纲、守恒、单调性和边界情形锁定答案量级；
- 构造至少一个解析特例或可手工复核的小算例；
- 用不同离散方式、独立几何实现或不同积分器复算；
- 报告网格、步长和容差收敛，区分模型误差与数值误差。
- 每问必须形成机器可读的“物理闭合与精度预算”：对象与坐标系、状态量及输入输出、控制方程来源、初始/边界条件、单位和量纲、近似项及适用域、观测量到答案量映射、守恒/约束残差、离散误差、参数不确定性和最终有效数字。
- 关键残差与误差必须同时记录指标、单位、阈值、实测值和通过状态；最终报告精度不得高于合成不确定度允许的精度，也不得只写“误差较小”或“结果稳定”。

### 4.2 逆问题与参数估计

- 先做合成数据参数回收，再处理真实数据；
- 检查目标函数剖面、多初值结果和参数相关性，识别多解或弱可识别；
- 使用不同信息来源的估计器交叉验证，如全谱拟合与极值级次、双角度与单角度；
- 用惩罚复杂度的准则、留出残差或可解释的物理判据决定是否升级模型；
- 把材料常数、边界选择和仪器误差传播到最终答案。

### 4.3 预测、分类与统计决策

- 基线、主模型和挑战模型使用完全一致且无泄漏的数据划分；
- 时间数据只做时间外推或滚动验证，不随机打乱未来；
- 同时检查平均误差、尾部误差、校准和置信区间；
- 阈值由训练/验证数据或决策损失确定，测试集只用于一次冻结评估；
- 复杂模型未稳定优于基线时保留简单模型。

### 4.4 评价与排序

- 检查指标方向、量纲、冗余和权重来源；
- 使用替代归一化、权重扰动、指标删减和支配关系挑战排名；
- 名次差小于扰动范围时报告同档或稳定区间，不制造精确名次。

### 4.5 优化与调度

- 先获得一个可行 incumbent，再寻找松弛界、解析界、对偶界或缩小实例的精确最优解；
- 同时使用全局探索和局部细化，记录多初值、多随机种子和候选解多样性；
- 对候选池、固定路径、分层分配等降阶逐步扩大邻域，量化目标改善是否仍在继续；
- 能计算界时报告 gap；不能计算界时只称“当前最优”“近优方案”或“最佳已知方案”；
- 停止条件同时考虑目标改善、可行性、界差和多次运行稳定性，不能只看算法返回 success。

### 4.6 仿真

- 报告重复次数、随机种子、置信区间和样本量收敛；
- 用解析均值、守恒量或另一实现核对随机机制；
- 比较方差与效应量，避免把随机波动解释为方案优势。

## 5. 答案充分性门禁

每问的 `metrics.json` 必须包含 `答案充分性`，并全部通过：

1. **题面闭环**：最终数值、方案或判定逐项覆盖必答内容；
2. **物理或约束可行**：单位、边界和全部硬约束通过；
3. **独立验证**：验证不复用主求解的同一误差来源；
4. **数值分辨率**：离散、抽样或迭代误差小于答案精度；
5. **替代路线挑战**：至少一条异构路线未推翻核心结论；
6. **不确定性或最优性**：给出误差区间、可识别性、界、gap 或近优证据；
7. **状态**：仅当前六项均通过时写 `PASS`。

若任一项失败，继续求解或降低结论强度。不得用多种子稳定代替全局最优性，也不得用拟合优度
代替物理正确性。

## 6. 论文中的模型选择

模型选择是否进入正文由其论证价值决定：

- 候选模型改变最终答案、复杂度升级需要解释、或挑战路线提供独立验证时，必须写；
- 只用短段说明最终采用路线及真正影响答案的决定性理由，不制作候选方法比较表；
- 跨问题共享的选择放在问题分析，单问特有选择放在该问模型小节；
- 只写真实执行过的候选、决定性指标和选择理由，不写内部文件名、代码入口和试错流水账；
- 基本规律唯一且替代路线只承担复算时，用一句话说明主模型与复算路线即可。

推荐表达直接陈述信息差异和证据，例如：

> 峰间距法忽略色散，频谱峰只能提供光学厚度初值；双角度相位拟合同时利用色散和角度信息，
> 因而作为主模型，极值级次回归保留为独立复算。

禁止写“为了显得更准确”“经过多次尝试最终选择”“满足模型建立要求”等制作或评审元叙事。

## 7. 证据结构

- `任务契约.json`：保存候选路线、淘汰条件和答案证据要求；
- `metrics.json`：保存冻结的模型选择、最终答案、验证和答案充分性；
- `证据矩阵.csv`：增加 `模型选择依据` 与 `充分性证据`，连接论文结论和结果文件；
- 内部结果文件：保留主候选与挑战路线的可比指标，不只保存胜者，但不直接搬入论文正文；
- 图表：优先展示决定模型选择或答案可信度的残差、gap、收敛、剖面或稳健性，不画装饰性比较。

## 8. 回归与发布

- 路由测试检查候选路线由题目结构产生，且未泄漏同题答案；
- 证据包测试检查每问的模型选择和答案充分性字段；
- 留出题在答案冻结后由独立评估者读取隐藏参考或独立高精度结果，写
  `审查/盲测答案评估.json`；求解者不得看到该文件；
- 盲测同时检查约束正确、相对误差/目标差、结论方向和不确定性覆盖，阈值按题型预先声明；
- 任何因看到隐藏答案而返工的项目只计作开发样本，不计作留出题通过。
