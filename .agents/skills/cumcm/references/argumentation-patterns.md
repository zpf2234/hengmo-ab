# CUMCM 论证叙事模式

本规范提供论证段落的正向写作指导，使每段承担明确职责、每个结论有证据支持、
各章节之间逻辑连贯。来源于 50 篇优秀论文的内容职责画像和逐问链分析。

## 全文口吻与 A053 主锚

摘要与正文统一采用参赛队向评委讲述当前题目理解、判断和真实求解过程的书面口吻。起草时就读
[A053 句法与叙事规范](../../cumcm-deai/references/a053-narrative-grammar.md)，以其对象起句、
推理承接、公式解释和结果作答的节奏为主锚，其他优秀论文补足题型差异。风格约束贯穿起草、
改写与审查，不只在末尾去 AI 时使用。

让评委沿着本题条件理解“为何有这条关系、怎样求这个量、结果意味着什么”。自然使用“我们”
说明有证据的建模判断与计算动作，也让对象、条件、公式和数据作主语；不设人称次数配额。
讲述仍保持数学论文的准确与克制，不称呼评委，不写讲稿式招呼或空泛预告。假设、符号表、
参考文献等按各自职责表达，不为统一口吻强加第一人称或整套推理。

每问标题后的概述段是必备内容，按
[逐问题意理解与建模入口](per-question-understanding.md) 从本题任务、决定性关系和求解主线
起句，后文据此展开；不能把它删成直接列公式，也不能用相同句架重复概述。A053 提供叙述方式，
当前题目的模型与证据独立产生，不复制其句子或专属内容。

## 段落职责

每段围绕一个论证中心，以下职责用于检查其主要作用。允许定义、推导和解释围绕同一局部判断
自然承接；每问概述也可合写任务、决定性关系与路线，不机械拆成多个段落。

| 职责 | 段落该做什么 | 段落不该做什么 |
|------|------------|--------------|
| 定义/口径 | 界定对象、变量、目标、约束 | 不展开推导或给结果 |
| 推导 | 从已知关系推出新关系 | 不重复定义或跳到结论 |
| 求解 | 说明数值/算法步骤和参数 | 不抄教科书或展示代码 |
| 证据 | 展示数据、图表、验证结果 | 不做空泛评价 |
| 结论 | 直接回答原题的问题 | 不重复推导过程 |
| 边界 | 说明适用范围和失效条件 | 不空泛地说"有局限性" |

一个段落若没有明确职责或只重复前文，应删除或合并。

## 单问论证闭环

每一问必须可反向追踪为完整链条，但不需要六个独立标题：

```text
题面要求 → 开头概述与数学转化 → 界定口径与变量 → 建立模型关系
         → 说明求解过程 → 展示结果与验证
         → 用具体结论直接回答原问
```

**检查方式**：从题目要求出发，能否在正文中依次找到对应的变量定义、模型公式、
求解步骤、数值结果、验证证据和直接回答？缺少任一环节即为断链。
建模完整性同时按 [逐问题意理解与建模入口](per-question-understanding.md#建模完整性) 逆向
检查条件、情形、参数和输出恢复，不能只因上述环节有同名标题而判定完整。

## 证据密度

每个结论性断言必须在 ±2 段内有数值、图表或公式支持。

**合格**："经四阶龙格-库塔法求解，第 10 s 时浮子位移为 0.1845 m（表 1），
与解析近似解偏差 0.3%（图 5）。"

**不合格**："经过求解，得到了满意的结果，验证了模型的合理性。"

## 论证连接词

用有信息量的连接替代空泛过渡词：

| 禁用 | 替代 |
|------|------|
| 此外 | （直接另起主题句） |
| 综上所述 | "由式(X)和表Y可知……" |
| 值得注意的是 | （直接写值得注意的事实） |
| 首先…其次…最后 | "对[对象A]…对[对象B]…" |
| 为了便于理解 | （删除，直接写内容） |
| 由上述分析可知 | "将[具体条件]代入[具体公式]" |

连接必须承载信息——前文产生了什么结果、后文需要什么输入、两者之间的因果或约束关系。

## 跨问衔接

前问输出作为后问输入时的标准表达模式：

**衔接句放在后问开头**，而不是前问结尾：
- "问题二在问题一求得的 $x_1(t)$ 基础上，进一步优化阻尼系数 $c$。"
- "利用问题一中已标定的弹簧刚度 $k = 80575\,\text{N/m}$，问题三的模型增加……"

**不使用**：
- "前者回答了……后者回答了……"
- "为后续建模奠定了基础"
- "上述结果将在后文使用"

## 方法选择叙事

当存在实质候选路线且影响答案时：

**两条路线**：用一段话，按"问题特征→两条路线的关键差异→决定性证据→选择结论"组织。

**三条以上**：完整比较留在内部证据；正文仍只用紧凑段落说明最终路线和决定性理由，不制作方法表。

**基本规律唯一时**：一句话说明主模型和独立复算路线，不为凑内容制作对比表。

**禁止**：列未运行算法为"备选"、展示内部试错流水账、用"先进"替代证据。

## 失效条件与适用边界

每个重要结论都应说明适用范围。写法：

- "当 $Re < 2300$ 时上述层流假设成立；湍流条件下需采用[替代处理]。"
- "上述排名在权重扰动 $\pm 20\%$ 内稳定；当 XX 权重降至 0 时，排名逆转。"
- "模型假设各连接为理想铰接；若存在间隙或弹性，[受影响结论]的误差可达[量级]。"

不得只写"模型有一定局限性"而不指出具体条件。

## 数值与文字的平衡

50 篇优秀论文建模段每千字数值词中位数为 60.46，结果验证段为 49.38，
而问题分析段仅 11.51，问题重述段 23.55。

这意味着：
- 建模和结果段应以数值、公式和图表为主体，文字服务于串联和解释
- 分析段以逻辑推理为主，数值为辅
- 重述段以信息转述为主，不需要大量数值

各章段的数值密度应符合其职责，不在分析段堆数字，也不在建模段缺数字。
