# CUMCM A/B 模型与算法路由目录

## 1. 定位与边界

本目录面向 CUMCM A、B 题的国一候选求解，但 **A/B 只是语料范围，不是选模特征**。
不得根据题号字母预设“连续题”或“离散题”，也不得把历年同类题的模型、参数或答案机械迁移到
新题。实际路由只由研究对象、状态演化、观测结构、决策变量、约束和不确定性共同决定。

本目录解决三个问题：

1. 生成有结构差异的候选路线，而不是罗列热门算法；
2. 为每条路线绑定适用条件、必要验证、停止条件和结论上限；
3. 让基线、主候选、异构挑战与 fallback 都可执行、可淘汰、可复核。

模型描述现实关系，算法负责估计、离散或搜索。论文必须先说明模型为何成立，再说明算法为何能
可靠求解；算法名称不能代替建模推导。

## 2. 先识别问题签名

每一问先填写下列七项，再进入模型竞技场：

| 维度 | 必答问题 |
|---|---|
| 对象 | 连续介质、刚体、曲线曲面、网络、生产系统、样本还是人群？ |
| 状态 | 静态关系、连续时间演化、离散状态转移还是事件驱动？ |
| 观测 | 直接观测、间接反演、带噪测量、删失数据还是只有规则？ |
| 决策 | 无决策、连续参数、离散组合、路径/排程还是序贯策略？ |
| 约束 | 守恒、几何、逻辑、容量、概率、风险还是资源边界？ |
| 不确定性 | 测量误差、过程随机性、参数区间、场景变化还是模型歧义？ |
| 交付 | 参数、预测、分类、排序、可行方案、最优值还是完整策略？ |

若同一问同时出现多种签名，按“共享状态模型 + 估计层 + 决策层”分层，不强行归入单一类别。

### 最小充分选择顺序

先给每问冻结准确性、约束可行、独立验证、稳健性、计算预算和可解释性门槛，并声明拟改善的
指标。解析/直接计算、完备枚举、经典统计与确定性优化可提供透明参照；同时允许从题目提出
新视角、结构改进和算法改进，按
[创新与组合规则](../../cumcm-model-tournament/references/innovation-and-composition.md) 设计试算。
候选探索不以简单路线先失败为前提；满足硬门槛后比较实际收益与新增复杂度。

复杂路线只有同时满足以下条件才能取代简单路线：

1. 修复简单路线的明确失败，或在基线已达标时取得预先声明的有实际价值的额外收益；
2. 改造有题目依据和可计算的作用机制，而不是只更换算法名称；
3. 增益在独立验证中稳定，且大于数值或抽样不确定性；
4. 参数来源、约束处理、停止条件和复现成本完整；
5. 新复杂度引入的过拟合、局部最优或随机风险已有额外验证。

候选收益相当时优先简单路线；新方法确有精度、速度、可扩展性或解释收益时，可以采用。
不要求每问创新或三类创新齐全。模型竞技不要求复杂方法获胜，国一
竞争力来自问题理解、推导、精度、验证和解释，不来自“智能算法”标签。

### 算法创新的碰撞控制

准备把算法改造写成创新时，先记录方案指纹：目标/约束、状态表示、更新或搜索算子、可行性修复、
自适应机制、停止条件、组合顺序和评价预算，并覆盖模型表示、观测关系和不确定性处理。比较范围遵循
[创新与组合规则](../../cumcm-model-tournament/references/innovation-and-composition.md)：先比较独立候选与
通用机制；历史同题材料只有在符合隔离要求的冻结后才能打开，赛中不得浏览当届解题讨论或其他队伍方案。
若只是同一算法换名称，或指纹高度重合而没有题目特定差异，就合并、淘汰或降低
声明等级。未做外部文献核查时，只能声称“针对本题的改造/适配”或“本试验下的实测改进”，不能
声称与其他队伍或其他 GPT 方案绝对不重复。

## 4. 模型族与算法族的使用契约

### 4.1 方程、离散与数值积分

- 常微分方程：非刚性系统可用自适应 RK45；刚性、强阻尼或多时间尺度系统比较 Radau/BDF。
  必须记录相对/绝对容差、最大步长、事件定位和状态约束处理。
- 偏微分方程：有限差分适合规则域和快速基线；有限体积适合强调通量守恒；有限元适合复杂域。
  必须报告网格无关性、时间步长、边界离散和守恒残差。
- 代数方程与事件：二分/Brent 用于有符号区间，Newton 类方法需导数与初值检查；关键碰撞、
  切换和阈值时刻须做区间夹逼，不以粗采样索引替代根。
- 降阶模型：集总参数、线性化、准稳态、模态截断可作基线或加速器，但要以无量纲判据、
  全模型对照和适用域证明误差。

### 4.2 参数估计、反演与信号处理

- OLS 只在误差结构近似同方差且观测独立时作为主估计；异方差用 WLS/GLS，异常值用可解释的
  稳健损失并保留原始残差对照。
- MLE 需要明确似然；贝叶斯反演需要可辩护先验、收敛诊断和后验预测检查，不能只输出后验均值。
- 正则化强度由留出、L 曲线、GCV 或物理约束选择；需区分数据不可识别与正则化人为收缩。
- FFT/STFT/小波/Hilbert 只解决频率、时频或相位信息提取；窗函数、频率分辨率、泄漏和相位
  展开必须说明。最终物理参数仍需观测方程映射与不确定性传播。
- Kalman/扩展/无迹滤波适合动态状态估计，不适合把任意平滑任务包装成“智能预测”；需检查
  过程噪声、观测噪声、创新白噪声和滤波一致性。

### 4.3 统计、试验与机器学习

- 线性/非线性回归、GLM、GAM、混合效应模型优先回答效应方向、交互和批次结构；先确认样本
  独立单位，避免把重复测量当独立样本。
- 响应面与 DOE 用于可控因素优化和追加试验；设计点覆盖不足时不得外推到远离数据的最优点。
- 树模型、随机森林、梯度提升、SVM 和神经网络只有在样本规模、特征结构和冻结验证证明增益时
  才升级。调参必须嵌套在训练流程内，测试集只评一次。
- ARIMA/ETS 适合稳定结构的时间序列；状态空间适合潜在状态与噪声分离；变点模型适合机制
  切换。任何时间序列都用滚动或时间外推验证。
- 聚类只有在分群能改变后续决策或解释时使用；簇数、距离度量和稳定性均需验证。

### 4.4 优化、搜索与决策

- LP/QP/凸优化优先保留对偶界和 KKT/可行性证据；MILP/MIQP 记录求解状态、最优界、gap、
  时间限制和容差。
- 非线性连续优化先检查变量尺度、约束资格和梯度；SQP、内点或 trust-region 需多初值与
  可行性复核。局部求解器 success 只说明满足其停止条件。
- 枚举、动态规划和分支定界适合可控状态空间，并可为小实例提供精确证据；状态压缩必须证明
  信息充分，剪枝必须有支配或界。
- 遗传算法、粒子群、差分进化、模拟退火、CMA-ES 等只作为复杂非凸空间的搜索器或挑战者。
  必须记录编码、可行性修复、种群/温度、停止条件、多种子分布和局部精修；单凭算法名和多次
  收敛不能证明全局最优。
- 多目标优先用 ε-约束或 Pareto 前沿保留权衡；加权和需要权重来源与尺度处理。最终推荐须说明
  偏好或约束依据。
- MDP/序贯决策需要状态满足 Markov 性、动作可实施、转移与损失有来源；若状态遗漏历史信息，
  应扩展状态或降低结论。

### 4.5 仿真与不确定性

- Monte Carlo 的前提是存在明确随机变量及分布/重采样机制。必须记录样本量设计、种子策略、
  估计量、区间方法、方差或有效样本量、停止规则。
- 稀有事件优先考虑重要抽样、分层抽样或解析界；普通抽样未观察到失败不等于失败概率为零。
- 参数不确定性、数值误差、场景变化和模型歧义分开报告；不得把多跑随机种子当成全部稳健性。
- 离散事件仿真检查事件顺序、预热期、批次均值和独立重复；排队或生产系统能解析核对时保留
  解析基线。

## 5. 自适应搜索与概率约束的统计认证

只要在多个候选点上估计概率，再依据这些估计筛选、淘汰或选择最优点，就存在选择偏差和多重
比较问题。单点 Wilson、Clopper–Pearson 或正态区间不能自动支持“所有候选均满足”。

必须在试算前冻结：

1. 候选总数与候选生成方式；
2. 总错误预算及点间分配方式，例如 Bonferroni/Holm、同时置信带或可证明覆盖的替代方案；
3. 固定样本还是序贯/自适应抽样；若自适应，使用在可选停时下仍有效的置信序列或独立确认集；
4. 淘汰、晋级、停止和最终确认规则；
5. 最终入选解是否使用独立确认样本重新估计；
6. 若无法同时认证，结论降为“抽样下最佳已知候选”并报告未控制的风险。

对于机会约束，至少保存：约束阈值、目标可行概率、置信水平、候选数、每阶段样本数、区间方法、
同时误差控制、停止条件和最终确认结果。不得由“若干点逐点通过”直接推出“全局高置信可行”。

## 6. 结论强度与证据对应

| 结论等级 | 可用措辞 | 最低证据 |
|---|---|---|
| L4 精确全局 | 全局最优、精确最优 | 穷举完备性、凸性/对偶证明、分支定界零或声明容差内 gap、可验证证书 |
| L3 认证近优/可行 | gap 不超过阈值、以给定置信度满足约束 | 有效上下界或同时概率保证，且数值/抽样误差预算闭合 |
| L2 最佳已知 | 当前搜索范围内最佳、近优候选 | 多方法/多初值、扩大邻域、小实例校准、停止条件与可行性复核 |
| L1 估计/探索 | 估计值、模拟结果、趋势 | 可复现估计、区间或误差、适用条件；不外推为全局结论 |

启发式搜索默认不高于 L2；逐点 Monte Carlo 且无同时控制默认不高于 L1。若模型歧义或参数不可
识别主导误差，算法求解再精确也不能提升结论等级。

## 8. 模型竞技场落盘要求

模型竞技场中的每个候选至少记录：

- 路由 ID、候选角色、模型方程/规则和算法族；
- 题面与参数来源、关键假设、定义域、边界/初始条件；
- 求解器、精度、停止条件、随机种子与约束处理；
- 硬淘汰条件、主指标、独立验证和失败信号；
- 结论等级上限及升级所缺证据；
- 实际运行产物，而非计划中的算法名。

../../cumcm-model-tournament/scripts/validate_ab_model_catalog.py。目录提供候选生成边界，不能替代题面
推导、真实编码与验证。
