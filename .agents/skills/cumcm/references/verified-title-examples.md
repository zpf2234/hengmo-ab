# 经原 PDF 核对的标题示例

2026-09-05 核对本地优秀论文的标题页及下列正文页。这是命名正例，不是整篇质量认证，
不把某篇的标题数量、长度或顺序设为模板。以下位置为 PDF 页序。

| 语料编号 | 原页总标题 | 原页章节标题 |
|---|---|---|
| A053 | 基于目标优化的板凳龙形态调节（第1页） | 问题一模型的建立与求解（第4页）；盘入碰撞检测模型的建立（第16页） |
| B007 | C4 烯烃制备分析与试验设计（第1页） | 问题一的求解与分析；数据预处理（第4页） |
| B203 | 基于0-1规划的单RGV动态调度模型（第1页） | 任务一的模型建立——方法一：考虑历史信号的调度模型（第5页） |
| A212 | 回焊炉温曲线优化控制（第1页） | 模型假设；符号说明及名词定义（第4页） |

由这些例子可见：常规章节名可以使用；对象和动作可结合父标题理解；有区分价值时允许较长的
条件说明，不能仅按字数判错。模型名称进入标题需对应实际内容，不能靠“严密、全局、正交”
等未被兑现的修饰增加气势。

`题目普查/all_paper_titles.md` 中仍有把摘要正文当题名的记录；`标题结构普查/all_paper_outlines.md`
也有把公式、列表和正文识别为标题的记录。二者只作为待核对索引，不直接复制其“标题”、
统计均值或分类。需要扩大样本时按编号定位原 PDF，核对标题页/章节原页，并保存页码。
不得因某一自动提取结果看似更长、更专业而采用；常规功能标题不属于专属措辞复制。
