# 国一候选：结果精度、直观论证与图示选择门禁

本规则适用于用户要求“国一、国奖、一等奖、优秀论文级”的 CUMCM 项目。目标是产出无明显短板的国一竞争候选稿，不承诺获奖。图数不设配额；图密度只作语料参照，放行依据是证据完整性、图示必要性和正文解读。

## 1. A 类机理/物理/数学题：精度优先

A 类题不按题号机械选方法，但一旦核心为物理、几何、微分方程、连续优化或数值计算，结果精度是首要门禁：

1. 所有最终数值必须能从题面原始量、求解脚本和结构化结果文件复算，不得由图读数或手工改表。
2. 报告精度之前必须完成步长、网格、容差或样本量收敛；数值误差至少比最终报告的末位小一个数量级。
3. 至少使用一种不共享主要误差机制的复核：解析特例、独立几何实现、另一积分器、守恒/量纲、穷举小实例或高精度局部复算。
4. 连续全局结论必须说明搜索区间、边界、候选峰/根的发现方式和局部细化；未证明全局性时只称“当前最优/近优”。
5. 每问在 `metrics.json` 中保存报告精度、数值分辨率、独立复核误差和失效边界。任一缺失不得放行。

## 2. 严密推导必须转成直观证据

公式正确不等于评委容易理解。物理/数学论证必须同时回答：

- 对象在哪里、方向和边界是什么；
- 变量之间如何传递；
- 临界、最优或首次事件发生在哪里；
- 为什么排除看似合理的基线方案；
- 数值误差与模型误差分别多大。

因此每个复杂子问题必须形成“解释—结果—验证/边界”的完整证据链，但证据载体不设配额：

- 文字和公式可解释机理、几何、变量关系及推导；
- 表格可承担题目要求的结构化答案和必要参数查阅，不展示候选模型、方法选择或验证对照过程；
- 图形可承担过程、构型、趋势、诊断或多变量关系。

可以零图、一图或多图。只有图形相对文字、公式或表格确有信息增益时才使用；同一问出现 4、6 幅
或更多图也可以，但每幅必须承担不同或互补的证据职责，并与正文形成合理交互。

## 3. 问题分析与模型建立的图示信息增益门禁

流程图不是“复杂问题”的默认产物。先比较短文、公式、表格与图示：只有关系或分支难以用前三者
清楚表达，且图能明显降低评委重建求解链的成本时，才使用可编辑矢量流程图。下列情形提示图示
可能有信息增益，但任何一项单独出现都不构成数量配额或强制触发：

- 非平凡判断、循环、回退、早停或状态转移相互嵌套；
- 粗搜—细化、候选生成—筛选—复核之间存在容易误读的返回或淘汰关系；
- 多层装配、递归、再生、动态规划或多对象输入输出需要同时追踪；
- 仅靠连续文字和公式难以快速重建分支条件、反馈位置或对象传递。

三个以上阶段本身不足以要求流程图。简单闭式代入、单一线性变换以及能由短文和公式清楚说明的
过程不画；目标奖项也不改变这一判断。

一旦决定使用，流程图必须：

- 参考本地 50 篇优秀论文的人工学术风格，但不得像素复制；
- 一张图只承担一个问题或一个关键算法职责；
- 节点写真实对象、状态、公式量和动作，禁止“数据处理—建立模型—得到结论”；
- 判断菱形写实际条件，分支标“是/否”或阈值，回路返回真实更新节点；
- 主轴 5–8 个节点，必要时拆成“问题关系图 + 局部算法图”；
- 白底、黑灰细线、至多一种冷蓝强调色，无渐变、阴影、图标和彩色卡片；
- 最终插入尺寸文字不小于 8 pt，主轴、分支和回路在缩略图中仍可识别；
- 保留 `.vsdx` 或 `.tex`、PDF、SVG、PNG、结构化 JSON、连接审计和视觉复审记录。

## 4. 语料视觉参照与逐问深度

开工前优先选择 3--5 篇同类型优秀论文；同题材料只在独立求解和答案冻结后使用。候选稿与参考稿
都按同一官方正文口径统计图密度，用于判断是否值得复核漏图或冗余，不产生数量下限或上限。
缺少同题基准不能阻断新赛题。

图密度低于参考 Q1 时检查是否遗漏关键空间判据、趋势或诊断；高于 Q3 时检查是否重复表达同一
命题。只要证据已由文字、公式、表格或高信息密度图充分承担，低密度不扣分；只有重复、无读数、
无来源或仅为填页的图才因冗余扣分。正文深度由写前完整论证规划、逐问八项职责、独立验证、
稳健性/失效边界和最终作答映射直接审查。

## 4A. 特色主视觉图门禁

复杂国一/国奖候选通常规划 2--3 张特色主视觉图，至少一张同时连接模型机制与最终结论。完整读取 `../../cumcm-figures/references/signature-figure-standard.md` 与 `../../cumcm-figures/references/visual-identity-and-archetypes.md`。特色必须来自真实数据关系、临界边界、策略景观、时空演化或不确定性—决策联动，不来自渐变背景、图标堆叠、装饰性3D和信息图插画。

figure registry 使用 schema v4。特色图必须登记 `signature_figure=true`、archetype、核心命题、十秒结论、阅读顺序、数据链路、面板题注规则、基础图证据增强、缩略图和最终页视觉复核；缺少这些字段时不得以“有特色”为由获得可视表达加分。国一模式至少一张合格特色图；若复合表达会重复或歪曲证据，可提交具名、绑定 claim/审查证据且经独立批准的豁免，不强制拼图。豁免不降低科学、provenance、MCP 图质量、正文合理交互或可视表达门禁。其他常规图仍保持克制，避免每张图都复杂化而破坏论文节奏。

## 5. MCP 图形精度与质量

1. Python 数据图/TikZ/Visio 必须记录真实生成来源（生成脚本或 MCP 调用），配置存在不等于调用成功。
2. 数据点、阈值、几何坐标和分支必须来自结果文件或结构化规格，禁止手工移动改变含义。
3. Python 数据图保留 `.py/.json/.pdf/.svg`；TikZ 保留 `.tex/.json/.pdf/.svg`；Visio 保留 `.vsdx/.json/.pdf/.svg`。
4. Visio 导入 SVG 按源 `width/height` 或 `viewBox` 等比缩放；面板比例形变率不得超过 0.2%。独立 PDF/SVG 特色图还必须同时核对目标宽度与目标高度，两轴最终尺寸误差均不得超过 0.2%；同倍放大虽不改变纵横比，仍会破坏插入后的字号与线宽，必须拒绝。
5. 参考图复刻必须固定画布、位置、线宽、文字和层级；原创图也要在最终论文插入尺寸审查。
6. 自动门禁不能替代人工视觉复核。每张核心图检查：字体压缩、标签碰撞、裁切、连接语义、留白、灰度辨识、数值一致性。
7. 核心图视觉审查失败时，必须修 MCP 规格或生成源并重新出图，不得只在 LaTeX 中缩放遮掩。

## 6. 放行

`PASS_NATIONAL_FIRST_CANDIDATE` 必须同时满足：结果精度门禁、逐问证据门禁、图示必要性与一致性门禁、
图表与正文合理交互、官方正文页数门禁、MCP 图质量门禁、总分不低于 57/60、可视表达 5/5、P0/P1 为 0。
否则仅可标记 `REVISE_NATIONAL_FIRST_CANDIDATE` 或 `BLOCKED`。
