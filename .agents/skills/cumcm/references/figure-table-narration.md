# 图表题注、引用与解读标准

本标准规定图题、表题怎么写，正文怎么引出图表，图表前后的解读文字怎么组织。统计口径
来自 50 篇优秀论文：631 条有效图题（`图形普查/figure_inventory_final.csv`）、153 条
表题与 672 条图表引用句（48 篇文本层 PDF 全文扫描，2026-08-13）。统计用于校准句式与
信息密度，不是配额。

## 语料事实

- 图题长度 P10/中位/P90 为 6/13/36 字；表题为 6/14/24 字。
- 句子式图题仅约 4%（其中多为 OCR 误并正文）：题注的常态是名词短语，不是句子。
- 约 35% 图题携带条件参数（"前 40 周期""t=10s""阻尼系数固定时"）。
- 引用句式分布：指示式（如图 X 所示 186、如下图/表 152、见图/表 46、如表 X 所示 54）
  约占三分之二；观察式（由/从图表可知、看出）约 10%；主语式（图 X 给出了）不足 2%。
- 49/50 篇有图号交叉引用，47/50 有表号引用：凡图表必被正文编号引用。

## 题注写法

1. 名词短语式，不用完整句子：写"阻尼系数恒定时结果曲线"，不写"该图展示了阻尼系数
   恒定时的结果变化情况"。题注末尾不加句号。
2. 结构为"限定条件 + 对象 + 量/关系"：条件参数入题注（"前 40 周期垂荡位移与速度"
   "调头前后部分把手速度"），使图表脱离正文也能自明。
3. 表题中的统一单位放题注尾部括号（"（时间单位 s，位移单位 m）"），或放表头列名中，
   两者取一，不重复。
4. 同一物理量在图注、表题、正文与摘要中的名称、符号和单位完全一致。
5. 禁止空泛题注："结果图""数据表""仿真结果""示意图"单独成题注一律不合格；题注
   长度低于 4 字视为空泛。
6. 长题注（超过约 36 字）先压缩限定语；解释性内容移入正文解读，不写进题注。

## 引用句写法

1. 凡正式编号的图表，正文必须至少引用一次编号。语料中"如下图/如下表所示"是高频
   句式（152 条），但那是 Word 顺排版面的产物；本工作区用 LaTeX 浮动环境，图表实际
   位置会移动，"上图""下图""如下表"等位置指代一律改写为"如图 X 所示"编号引用，
   位置指代仅在人工确认环境为固定位置（`[H]`）时可保留。
2. 三种语料句式按职责选用：
   - 指示式（主力）："……，如图 3 所示""各时刻状态如表 2 所示"——用于结果落地，
     句子主体仍是结论或操作，图表编号收尾；
   - 观察式："由图 3 可知，浮子与振子的绝对位移十分接近"——用于从图表读出证据、
     推进下一步推导；
   - 操作锚定式："如图 2 所示，对浮子和振子分别进行受力分析"——用于把图作为推导
     的几何或结构参照。
3. 避免连续多段都用同一句式收尾；指示式与观察式交替出现是语料常态。
4. "结果见表 2"可以作为落点句；只要相邻上下文已经明确对象、条件或结论，就构成合理交互。
   完全脱离上下文的裸指路句转人工复核，不直接按固定句式判失败。

## 解读文字组织

每一幅编号图和每一张编号表都要与正文形成合理交互，但不设置统一的前后段落模板。交互可以是：

- 在当前推导中定位对象、坐标、连接、阶段或判据；
- 为结论提供趋势、极值、区间、空间关系或关键读数；
- 汇总题目要求的最终答案；
- 承接验证结论、边界或下一步计算。

关键数值、原因、验证判定和对答案的影响仍须在本问整体论证中完整出现，但不要求每幅图表分别重复，
也不要求固定为“图前说明—图后观察—关键数值—原因—答案影响”。自动审计硬查非空题注、标签和
编号引用；引用邻域信息较弱时只列为人工复核项。仍不得写"由图可知效果很好""从表中可以看出结果合理"
等空泛评价，也不逐行念表。
