# CUMCM 数学写作规范

本规范统一全文的变量引入、公式叙事、推导组织、边界条件表达和数值精度报告，
使正文读起来像一个连贯的数学论证而不是代码注释或算法说明书。
来源于 50 篇优秀论文的建模段分析：92.9% 出现定义信号，88.1% 出现机理关系，
76.2% 出现参数来源，每千字数值词 60.46——是全文技术密度最高的区域。

## 简洁符号与下标

全文采用简洁主符号，遵守用户“不用复杂下标公式”的要求，并延续 A053 的克制写法。

- 能写成单字母或由当前上下文区分的量，不加对象、问题编号、阶段或场景下标。
- 确需区分对象时使用一层短下标，如 `x_i`；对象与时间优先写成 `x_i(t)`，两对象关系可用
  `d_{ij}` 并就近定义索引。必要的标准矩阵或数组索引保留其真实语义。
- 不使用下标内嵌下标、长串描述下标，或把对象、时间、场景和算法状态全堆在同一个符号上。
  将时间写为自变量，情形通过局部说明区分，复杂关系拆为有对象含义的中间量或矩阵关系。
- 简化须保持原模型的索引域、对象对应、约束与计算含义，并同步符号表、图表和代码映射；
  不能删掉必要区分使两个不同量变成同一符号。复杂下标必须改写，不能仅补一句解释原样保留。

本要求从求解侧变量设计开始执行，在成文与符号审查时再次核对；不限制必要公式数量或推导深度。

## 变量引入

先说物理或数学含义，再给符号，最后定义域和单位。不在公式后才解释。

**正确顺序**：
- "设浮子在时刻 $t$ 的垂荡位移为 $x_1(t)$（单位：m），其中 $t \in [0, T]$。"
- "令目标函数为平均输出功率 $\bar{P}$（单位：W），决策变量为阻尼系数 $c$。"

**错误顺序**：
- "由式(3)可知 $x_1$ 为……"——读者在式(3)处不知道 $x_1$ 是什么
- "定义 $f(x)$，其中 $x$ 表示……"——先给了空壳再解释

符号在符号说明表和首次使用处都应可定位定义，但正文不得写
"首次出现处定义""见下文定义"等阅读安排。

## 公式动机

每组公式前用一句话说明"为了什么目的，需要建立什么关系"：

- "为求取浮子的运动规律，对浮子—振子系统列牛顿第二定律："
- "为确定最优阻尼系数，以平均功率为目标建立优化模型："
- "将边界条件代入通解，确定待定系数："

不得直接写"由以下公式可得"或"建立如下模型"而不说明目的。

## 成熟公式与本题推导

正文以评委熟悉的数学表达组织真实建模过程，成熟公式与公认定理使用惯用形式。本题推导或
改造的关系也应从对象和条件自然引出，使读者能顺着必要步骤核对，而不靠符号复杂度体现创新。

- **成熟公式、公认定理**：准确写明所用关系或定理及本题满足的必要条件，保留学科惯用符号，
  说明它连接了哪些已知量和待求量。标准证明不重复展开；非基础常识或关键外部关系给可核查
  出处，不为显得原创换名称、堆修饰或重新发明等价表达。
- **本题自行推导或改造的关系**：先说明从哪项题面事实、机理、假设或已知关系出发，再定义
  少量必要量，展开决定性步骤，得到核心式并解释其作用。长复合式拆成有含义的中间关系；
  每步让评委看清增加了什么条件或完成了什么转化，不突然抛出整套自创符号。
- **关系性质与依据**：定义、定理推论、近似、经验拟合与待验证假设分别如实说明；自行构造的
  指标、目标或经验修正不能称为公认定理。新推论需有成立条件和必要证明，近似或拟合需有
  误差与验证依据，结果可信度不得靠流畅措辞补足。
- **局部阅读可理解**：公式前说明本题目的与来源，式后解释关键项怎样作用、怎样进入计算或
  回答原问。评委能从相邻文字理解主关系；符号表、引用和标准术语支持查阅，不代替本题解释。

成熟关系与本题改造可以结合，选择由题意、适配性和验证决定。表达简洁不省略关键推导、
条件或证据，也不要求把所有公式改成最初等形式。保持 A053 主锚的对象、关系与结果承接，
自然解释实际数学动作，不套统一的公式引出句或反复宣布“我们建立了”。

## 公式认知负担

评委应能在公式所在段落完成理解，符号说明表只用于查阅，不替代局部定义。复杂度以表达题目关系所需
的最小层级为准，不以符号多、下标深或式子长体现建模水平。

- 一个展示式优先承担一个主关系：定义、机理、目标或约束不要无故混写；真正的方程组、约束组和
  分段关系可合写，但正文先说明它们为何属于同一组。
- 先定义有对象含义的中间量，再写复合变换、长聚合或优化主式。若拆开后更容易核对，就不把推导
  压成一条大公式。
- 优先使用惯用主符号和一层短下标；下标中不继续嵌套下标，复杂对象与时段关系按上节改写。
  真值、估计量等采用最少的惯用修饰并就近解释，避免帽号叠横线和多套花体。
- 公式后不仅解释“符号代表什么”，还要说明主项如何作用、约束方向是什么，以及该关系怎样进入
  下一步或产生题目要求的输出。

不设置“每式最多几个符号”等任意阈值。自动审计发现的是阅读风险；风险必须通过简化、拆式、补充
前后说明消失，或留下能被评委直接核验的保留理由；复杂下标按上节改写，不用保留理由免除简化。

## 推导叙事

**展开原则**：本题特有的关键推导步骤必须展开，使读者能验证结论；
常规代入、化简和标准算法步骤可省略但必须说明依据。

**推导段结构**：
1. 说明推导目标（从什么到什么）
2. 给出起始关系和适用条件
3. 展开关键步骤，每步说明操作（"将式(X)代入式(Y)"/"对两端取极限"）
4. 得出结果，指出其物理或数学含义

**禁止两个极端**：
- 逐行抄教科书：如完整展开龙格-库塔公式的四个中间量
- 跳跃过大：如从受力分析直接到最终数值结果，中间无推导

## 边界条件与初始条件

边界条件和初始条件与主方程具有同等地位，必须显式呈现：

- 与微分方程或优化模型紧邻放置，不藏在正文段落中间
- 说明边界条件的物理来源（"自由端""对称性""初始静止"等）
- 若边界条件来自题面数据，注明数据来源

## 参数表达

参数在正文中必须有来源说明：

| 参数类型 | 表达方式 |
|---------|---------|
| 题面给定 | "取题面给定值 $m = 4000\,\text{kg}$" |
| 物理常数 | "取 $g = 9.8\,\text{m/s}^2$" |
| 文献取值 | "参照[X]，取 $\mu = 0.3$" |
| 估计/标定 | "由最小二乘拟合得 $k = 80575\,\text{N/m}$，$R^2 = 0.997$" |
| 优化结果 | "经全局搜索得最优值 $c^* = 37639\,\text{N·s/m}$" |

不得出现来源不明的参数值。

## 数值精度报告

- 有效数字由测量精度或计算精度决定，不随意保留或截断
- 同一表格同一列使用相同的有效位数
- 百分数统一注明分母或基准
- 优化目标值报告时同时给出界或 gap（如"最优值 3.27 kW，松弛下界 3.15 kW，gap 3.7%"）
- 区间估计给出端点和置信水平
- 不用"约""大概""近似"替代具体数值

## 公式与正文衔接

- 引出展示公式的最后一句以中文冒号"："结束
- 公式末尾不加标点；编号后不追加标点
- 公式后必须有衔接：解释关键量、说明下一步操作、或给出结论
- 正文引用统一写"式（1）"
- 同组并列约束或状态方程用左大括号 + `aligned`，共用一个编号
- 连续推导不机械添加大括号

## 表格规范

**何时用表**：
- 题目明确要求填表，或最终答案天然由多个对象、时刻或情形组成时
- 列出参数及其来源时

候选模型、方法筛选、试算过程、主结果与验证结果对照不进入正文表格；相关证据保留在内部文件。

**何时用图**：
- 展示趋势、分布、空间结构或时间演化时
- 展示残差、收敛或诊断信息时
- 数据维度超过表格能清晰展示的范围时

**表格与图的分工**：同一结果不同时用完整图和完整表重复呈现。

**表格格式**：
- 正文使用编号自然引用，使表格与答案、参数或当前推导形成明确联系
- 同列同精度、单位在列头
- 按题目要求或数值大小排序，不按内部计算顺序
- 不强制表前、表后各设置固定说明段

## 图表与正文衔接

图表与正文按论证需要自然衔接，可以承担对象定位、读数、关系解释、判据或答案汇总。关键数值、
原因和答案影响应在本问论证中完整出现，但不要求每幅图表分别套用固定的前后四步。不得写
"由图可知效果很好"或只描述图的外观而不解释含义。
