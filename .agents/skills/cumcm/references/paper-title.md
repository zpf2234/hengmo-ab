# CUMCM 论文总标题

本规则用于论文封面总标题，不替代章节标题规则。语料统计只用于校准，最终标题必须由当前
题目的模型、结果和证据生成。

## 普查数据质量

本地题目普查覆盖 A、B 题优秀论文各 25 篇，但自动提取结果中存在把摘要正文、公式或页内
句子误识别为标题的记录。使用普查结论前必须：

1. 优先读取标题页的版面标题；
2. 用 PDF 文件名和文档元数据交叉核对；
3. 出现“本文主要”“首先采用”“通过……求出”等完整陈述句时，判为正文片段并重新提取；
4. 不用未清洗 OCR 的字数均值、句式分类或关键词频率制定硬规则。

按稳定 PDF 文件名回算的 50 篇标题长度均值约为 16.4 字，其中 A 题约 14.8 字、B 题约
18.0 字；观察范围约 7--33 字。该结果说明标题通常简洁，但不形成字数合规线。
题目普查中雷点清单所称"均值 24.9 字、18--30 字最佳"为未清洗 OCR 口径，不采用。

## 一手语料对照与雷点自查

按 [corpus-alignment.md](corpus-alignment.md) 执行：先读
[已核对标题样例](verified-title-examples.md)。原 `all_paper_titles.md` 仅作定位索引，新增样例
须核对原 PDF 标题页，不用摘要误识别项或未清洗统计指导命名。只比较对象词、
动作词和方法词的组织方式；定稿前对照
`题目普查/AB优秀论文题目命名十大雷点与写作禁忌.md` 逐条自查（假大空、方法词未兑现、
照抄赛题名、超长复句、主客体倒置、口语化）。材料缺失时跳过。

## 标题构成

标题至少同时交代：

- 研究对象或任务场景；
- 建模、求解、控制、设计、评价、预测、调度或优化等核心动作。

核心方法或机理是可选项。50 篇稳定标题中约 17 篇显式出现方法或机理词，不能要求每篇
机械加入算法名。只有同时满足下列条件时，才把方法写入标题：

1. 方法决定了论文的主要模型结构或关键判据；
2. 方法在摘要、正文推导、求解实现和验证中均有实质证据；
3. 方法不是只在某个小问或辅助步骤中短暂使用；
4. 写入后能区分本文路线，而非增加术语密度。

## 三种优先句式

1. 对象 + 核心动作：适合任务边界清楚、单一目标突出的论文。
2. 基于核心机理/模型的对象 + 核心动作：适合机理或方法确实统领全文。
3. 对象 + 两项紧密耦合任务：适合分析与设计、定位与调整等双任务论文。

“基于 X 的 Y”不是默认高分句式。若 X 只是常规工具，改用对象与动作直陈式。

## 禁止项

- 不原样照抄赛题名称而不体现本文研究侧重；
- 不写正文没有实现和验证的方法，不用“非线性、智能、AI、深度学习”等词升格包装；
- 不并列三种以上算法，不把方法清单当标题；
- 不使用“若干问题研究”“相关问题探讨”等无对象、无动作的空泛名称；
- 不使用口号、评奖话语、夸张判断、句号或感叹号；
- 主副标题只有在两者职责不同且不可合并时使用，不机械添加副标题。

## 成稿检查

标题在求解证据稳定后再确定。提交前逐项核对：

1. 标题中的对象与论文实际对象一致；
2. 标题中的每个方法词均能定位到公式、实现和验证证据；
3. 摘要首段自然解释标题中的对象、机理和动作；
4. 标题没有被某一小问绑架，能够覆盖主要贡献；
5. 删除任一修饰词后若信息不减，则删除该词；
6. 与同题优秀论文只比较信息密度，不复用其专属标题结构。
