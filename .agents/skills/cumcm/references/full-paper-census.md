## 全文稳定脉络

```text
题面任务 → 问题分析 → 模型假设 → 符号说明 → 共享准备
         → 各问：模型 → 求解 → 结果 → 验证 → 直接回答
         → 跨问题检查 → 评价与边界 → AI 工具使用声明（2026）→ 参考文献 → 附录复现
```

该链条表示职责，不是固定目录。各问相对独立时可用分问题一级章；共享机理强时用总章统领；
多阶段或模块高度耦合时允许问题嵌入式、方法或模块驱动结构。

## 写作与审查用法

1. 先按题目依赖选择结构，再把每问的最终回答和证据位置标到标题树。
2. 默认采用“模型假设→符号说明”；若必须先定义符号，记录结构理由。
3. 每问在正文和证据中完成模型—求解—结果—验证—回答闭环，标题可合并职责。
4. 跨问题验证有实质证据时独立设章；否则在逐问验证后用一节汇总误差传播和共同边界，
   不为章名伪造实验。
5. 附录必须服务复现，但长度、语言、图数、表数、公式数和标题数不设配额；正文图数由待证明命题
   和不可替代证据职责决定。
6. 不复制语料的题名、句式、模型链、参数、结果、代码或图形。
7. 页数反馈同时报告官方正文和 PDF 总页数；官方正文统一按正文主体首页至附录开始前一页计算，
   不再使用旧普查的 23--27 页软校准带。
