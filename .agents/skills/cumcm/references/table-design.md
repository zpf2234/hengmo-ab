# CUMCM 表格设计规范

本规范统一全文表格的类型选择、列结构、排序、数值格式和正文引用方式。表格优先承担题目要求的
结构化答案，不展示模型筛选、内部试算或验证对照过程。

## 表格类型与适用场景

| 表格类型 | 适用场景 | 不适用场景 |
|---------|---------|-----------|
| 答案表 | 题目明确要求填表，或最终答案天然包含多个对象、时刻或情形 | 中间计算过程、为显得完整而列数值 |
| 参数表 | 模型参数及来源汇总 | 单一参数值（直接写入正文） |
| 数据描述表 | 数据字段、单位和范围 | 原始数据全量展示 |
| 符号表 | 第四部分主要符号 | 局部一次性符号 |

候选模型、方法选择、试算过程、淘汰原因、主结果与验证结果对照、内部敏感性扫描不制作正文表格。
这些材料保留在求解与审查文件；正文只用短句说明最终采用路线、验证结论或必要边界。

## 结果表标准列

题目要求的最终输出表：

```text
| 问题/情形/编号 | 决策变量/输入 | 目标值/输出量（单位） | 必要备注 |
```

- 按题目要求的顺序排列，不按内部计算顺序
- 必须包含单位
- 题面要求的置信区间、类别或排序可作为答案列；验证方法和内部判定不混入答案表

## 参数表标准列

```text
| 符号 | 物理含义 | 数值 | 单位 | 来源 |
```

- 来源列不可空：写"题面给定""文献[X]""拟合得到""优化结果"等
- 只收录影响结果的关键参数，不列所有中间量

## 数值格式

- 同一表格同一列使用相同有效位数
- 单位统一放在列头，不在每个单元格重复
- 百分数注明基准（如"相对于问题一结果"）
- 区间用"[下界, 上界]"格式
- 缺失值用"—"而非空白

## 排序原则

1. 题目明确要求排序方式的，按题目要求
2. 参数表按首次出现顺序或物理分组
3. 时间序列按时间顺序
4. 无特殊要求时按问题编号

## 表格与图的分工

| 信息类型 | 优先用表 | 优先用图 |
|---------|---------|---------|
| 题目要求的精确答案 | ✓ | |
| 趋势和演化 | | ✓ |
| 空间分布 | | ✓ |
| 参数与来源 | ✓ | |
| 残差和诊断 | | ✓ |
| 题目要求的排名和分类答案 | ✓ | |
| 收敛过程 | | ✓ |

**同一结果不得同时用完整图和完整表重复呈现**。
若需要同时用图和表，必须让两者承担不同的信息职责（如图展示趋势，表给出关键时刻的精确值）。

## 正文引用

- 正文使用编号自然引用表格，并说明该表在当前段落中承担的是答案汇总、参数查阅还是对象对应关系
- 交互可以位于表前或表后，不强制同时设置固定的引出句和分析段
- 只有"结果见表 X"且与上下文没有对象、结论或推导联系时，转人工复核
- 不得逐行念表
- 表题写法、引用句式分布与解读组织的语料标准见
  [figure-table-narration.md](figure-table-narration.md)，自动检查由
  `cumcm-paper/scripts/audit_figure_table_narration.py` 执行

## 禁忌

- 无标题、无单位的表格
- 截图或手工排版的数值表（必须由结果文件生成）
- 原始数据全量展示（附件数据放附录或支撑材料）
- 与正文图完全重复的信息
- 候选模型或方法比较表、选择/淘汰过程表
- 主结果与验证结果对照表、仅用于展示内部复核过程的敏感性表
- 表格内嵌长段文字（超过两行的说明改为脚注或正文）
