# A/B 题图形路由与人工学术风格

本规则来自本地 25 篇 A 题、25 篇 B 题优秀论文的图形普查。48 篇文本型 PDF 由版面块
提取图题，两篇 2025 扫描版逐页 OCR，并对各类别做分层页面目检。共得到 760 条正式
图号记录，其中 A 题 418 条、B 题 342 条。统计用于发现论证链缺口，不构成图数或图型配额。

## 证据职责与特色版面安排

1. **不设置图数上下限**：正文可以没有图，也可以出现 4、6 幅或更多图。是否入正文只由待证明
   命题、变量维度、读数任务及相对文字/公式/表格的信息增益决定；图数和 `body_pages` 不形成公式，
   不为页数或“版面饱满”加图，也不因图少自动扣分。
2. **多阶段演化采用多面板拼图 (Subfigures)**：
   - 借鉴 **2024A 板凳龙** 舞龙队运动演化、多阶段调头轨迹、螺线切点与碰撞临界状态的优秀论文范例。
   - 对涉及多时间点、状态演化、阶段对比或多变量梯度的题目，**使用多面板子图拼图（Subfigures：可根据数据逻辑灵活选择 (a)(b) 2面板、(a)(b)(c) 3面板或 (a)(b)(c)(d) 4面板）**。
   - **严禁机械凑 4 图**：面板数量必须严格由数据维度与待证明结论决定，每个面板均须有不可替代的论证职责。
   - 用一个图号集中呈现同一演化命题，减少碎片图和重复正文，不把拼图当作变相凑图。
3. **特色版面按证据选择**：模型选择流程、阶段演化、几何/临界构型、机理—结果联图、结果曲线与
   风险响应图均是候选原型；只有当前题目存在对应复杂关系和真实数据时才采用，不预分配数量。

## 先判职责，再选图型

为每个候选图填写“待证明结论、变量维度、关键读数、来源数据、生成工具”。任一项为空，
该图不进入正文。

同一命题可以用多幅图表达。4 幅、6 幅或更多图均可，但每幅必须登记不同或互补的职责，例如
整体趋势、局部边界、空间构型、误差诊断或情景对比；职责、读数和正文解释重复的图应合并或删除。

候选阶段只登记命题、数据和正文插入位置；待对应小节的文字、公式、符号与关键结论稳定后再绘制成稿。
这样图中对象名、变量、阈值和正文完全同源，避免先画后改造成错位。每问成稿后立即插图并编译，
不在全文末尾集中补图。

1. **模型解释图**：解释坐标系、对象关系、受力、投影、遮挡、关键截面或状态关系。
2. **方案结果图**：展示轨迹、路线、任务分配、测线、空间布设或调度时间窗。
3. **动态响应图**：展示状态随时间、距离、参数或迭代次数的连续变化。
4. **诊断验证图**：展示残差、分布、收敛、灵敏度、误差或基线比较。
5. **流程图**：先按 [flowchart-routing.md](flowchart-routing.md) 区分关系、分题、算法、数值和
   状态流程，只表达真实问题结构或实现逻辑。
6. **原始证据图**：只在图像识别、实物测量或遥感任务中保留必要的输入与识别结果。

## A/B 经验先验

- A 题若包含明确的物理或几何关系，优先检查“坐标/场景—关键几何判据—动态或空间结果”
  是否闭环。模型解释图通常早于结果曲线出现，不能用通用流程图代替。
- B 题优先检查“数据/状态诊断—空间或决策方案—拟合、比较或敏感性”是否闭环。路径、
  调度和定位类 B 题仍以路线与空间布设图为主。
- 题号不是强制规则。若实际问题结构与上述经验不同，以变量、模型和待证明结论为准。

## 图型判定

- 一维连续变化：证据增强曲线，至少带事件、阈值、边界、区间、基线或不确定性之一；离散观测或
  关系识别用散点；少量方案优先点—区间图或表格，柱图须有额外证据层。
- 区间接力与资源占用：时间线或 Gantt；路线与空间分配：二维轨迹或布设图。
- 高质量三维图在能增强空间关系、双参数响应、轨迹层次或核心结果展示时可以使用，不要求二维方案
  先被判为完全失效；是否采用由信息增益、可读性和最终版面共同决定。
- 热力图仅用于真实二维矩阵、空间场、相关矩阵或双参数响应，且两个坐标轴和颜色变量都
  有不可替代的读数职责。不得把一维序列、少量类别或普通方案表改画成热力图。
- 78 条流程/框架候选中复核确认 68 幅真正流程类图；不使用固定框数。若没有复杂依赖、
  判断或回退且文字更短，保留文字步骤。

## 制作工具

- TikZ：几何机理、场景关系、流程图和数学结构图的默认路线；按稳定成稿中的符号、公式与节点生成。
- Python（matplotlib）：工程曲线、三维轨迹、曲面、等值线、动态响应、统计诊断、批量数值图、
  验证图和自动化；本工作流全部数据图的统一路线。
- Visio/draw.io：仅在对象很多、规则布局明显不如人工编排时回退，并保留可编辑源与不用 TikZ 的理由。

PDF 元数据不能证明单张原图的创作软件。上述工具是复现路线，不作为原作者工具判断。

## 人工学术风格

- 白底、黑灰细线为基底；流程图默认不使用颜色编码，数值图确需区分类别时才使用克制配色。
- 几何图使用普通线段、圆/椭圆、虚线遮挡关系和直接标注；流程图使用矩形、标准菱形与
  直线或正交箭头。
- 禁止渐变背景、阴影、发光、装饰图标、圆角卡片、大面积彩底和营销式标题。
- 图内不重复论文图题；图题置于图下。坐标、单位、图例、线宽和中文字体统一。
- 两幅强耦合图可由总图题用“左/右”说明；三幅及以上或面板条件不同，统一在面板下方放小标题，
  再在整组下方放总图题。不得把面板标题塞进绘图区。
- 数值点、轨迹和曲面由结果 CSV/JSON 或脚本生成，不在 PowerPoint 中手工移动。
- 示意图允许人工调整排版，但关键坐标、方向、比例关系和标注必须与模型定义一致。
- 几何示意图使用固定画布和固定纵横比，文字、箭头、尺寸线与对应几何对象按坐标锚定；
  插入论文时只允许等比例缩放，字体替换或重新导出后必须逐页渲染检查错位、压线和越界。
- 几何图先执行 [geometry-diagram-routing.md](geometry-diagram-routing.md)，再与关系图共同
  执行 [diagram-layout.md](diagram-layout.md)：有框节点使用形状内嵌文字，
  对象外标注使用锚线，不允许源图紧边界导出或 LaTeX `trim/clip` 修补。
- 问题关系图只表达共享模型、依赖和递进关系，不额外叠加“逐问验证”汇总栏、评价口号或
  与关系职责无关的结论条。
- 每张核心图保留可编辑源文件、论文用矢量 PDF、来源数据和生成命令。

## 全篇视觉辨识度与特色图

国一/国奖候选在图形职责预算阶段额外执行 `../../cumcm-figures/references/signature-figure-standard.md`。
全局颜色/线型语义和 A/B 原型目录以
`../../cumcm-figures/references/visual-identity-and-archetypes.md` 为准，并在生成普通图前完成规划模板。
特色图不是固定图型，而是“核心问题叙事 + 高信息密度证据 + 独特视觉轮廓”的结合：

- A 类优先考虑临界构型、时空轨迹带、机理—结果三联图、参数相图和多精度闭合图；
- B 类优先考虑策略景观、策略指纹、不确定性—决策联动、真实概率流和全策略地图；
- 每篇复杂候选通常 2--3 张，至少一张连接模型机制与最终答案；不适合时记录豁免，不强制拼图；
- 特色图可以合并数张职责重复的普通图，但不能为“更特别”删除必要诊断证据；
- 特色图必须在缩略图形成清晰轮廓，并在最终页面 8--12 秒内读出对象、关键变化和结论。

## 审查门槛

- 图形密度低于同类论文 Q1 时只触发漏图人工复核；若职责已由文字、公式、表格或一张高信息
  密度图充分承担，不因图少扣分。
- 图形密度高于同类论文 Q3 时只触发逐图冗余复核；重复、无读数或仅为填页的图才记 P1。
- 几何或物理模型存在关键空间判据却无模型解释图：P1。
- 图型与变量维度不匹配、热力图无二维结构、三维图只有装饰效果或透视造成误判：P1。
- 数值图无法追溯到结果文件，或在演示软件中手工移动数据：P0。
- 流程图与实际脚本、判断或回退不一致，或用文件生产/交付流程代替模型逻辑：P1。
- 图中存在低清截图、文字过小、遮挡、越界、缺单位或颜色无法区分：P2；影响读数时升为 P1。
- 装饰图、重复图或只为填充页数而放大的图：P1。
