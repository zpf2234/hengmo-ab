## 评阅导向内容转写（讲评 PPT"竞赛论文的方法/常见方法"节，p70-p87）

### 问题 1（折射率模型与厚度计算基础）

- 论文中可用的折射率模型：Cauchy 色散方程 n(λ) = a + b/λ² + c/λ⁴（参数 a、b、c
  由文献提供），Sellmeier 色散方程 n²(λ) = 1 + ΣBᵢλ²/(λ²−Cᵢ)，以及介电常数公式。
- 学生常用的常数厚度计算公式：d = 1/(2√(n̄²−n₀²sin²θ₁)) · 1/Δω̄，其中 Δω̄ 为波峰
  （或波谷）间隔平均值——命题人明确这是"典型的常数计算公式"（隐含：只用常数
  折射率不满足题目要求）。
- 线性回归方法：由干涉级数关系 mᵢλᵢ = 2d√(n²(λᵢ)−n₀²sin²θ₁) + λᵢ/2，令 mᵢ = m₀+i
  化为线性回归 i = d·(2√(n²(ωᵢ)−n₀²sin²θ₁)) + (1/2−m₀) + εᵢ，斜率即厚度 d；回归前
  需先由折射率公式算出 n(ωᵢ)。

### 问题 2（外延层厚度的计算）

- 利用问题 1 的模型计算不同波长下的折射率，据此确定外延层厚度；用介电常数公式
  （式 33）或色散方程（式 34/36）加厚度公式（式 9），**外延层厚度大约 7.5 μm**。
- 由于可计算出厚度有多个值，**可用均值和标准差表示厚度的最终结果**。
- **如果使用常数折射率（如 n = 2.55），计算结果也会在 7.5 μm 左右，但没有达到题目
  的要求，哪怕它有文献（如国家标准）作为支撑**。
- 使用非线性最小二乘方法计算时，初始值的选取很重要（例如将 n 的初始值取在 2.55
  左右可能得到理想结果）。

### 算法设计的三性要求（评阅核心判据）

- **实用性**：计算过程不需要人工干预（如用 Matlab findpeaks()/Python find_peaks()
  自动求波峰波谷坐标，而不是手工操作）。
- **鲁棒性**：尽可能消除噪声对计算精度的影响（消除噪声很重要，只要使用平滑或
  滤波方法即可；学生使用最多的是 Savitzky-Golay 平滑滤波）。
- **一致性**：同一块晶圆片的计算结果应相差不大（很多学生误认为它是可靠性）。
  **一致性不好的结果肯定是有问题的，但一致性好的结果不一定是正确的**。
- 附件 2 中 600-1000 cm⁻¹ 部分数据反射率超过 100%，文献称 reststrahl band
  （剩余射线带），计算时不必考虑这段数据；即便不了解原因，它不具有周期性，
  也不适合于计算。

### 计算结果的可靠性（评阅核心判据）

- 可靠性分析十分必要：可利用附件数据验证结果合理性（例如用折射率和厚度的估计值
  计算干涉光谱的反射率，并与附件中的数据作对比）。
- **可靠性分析是想说明论文给出的计算结果是正确的。使用两种完全不同的方法而计算
  结果相近，可以作为可靠性的证明**。

### 问题 3（多光束干涉）

- 给出产生多光束干涉的必要条件（如外延层与衬底折射率的比值较大）；**必要条件最好
  给出定量的指标，并作为厚度计算精度影响的依据**。
- 这里是"多光束干涉"的必要条件，不是"光干涉"的必要条件；照搬百度的光干涉三条
  必要条件（平行分量/频率相同/相位差恒定）"肯定没有错，但无用"。
- 判断附件数据是否出现多光束干涉（硅数据中会出现），回答"是/否"应与前面的必要
  条件相一致，且都要给出理由；若回答"是"，需要改进原有厚度计算方法。
- 判断方法：比较双光束干涉模型 I = I₁+I₂+2√(I₁I₂)cosδ 与多光束干涉模型
  I = (I₁+I₂+2√(I₁I₂)cosδ)/(1+I₁I₂+2√(I₁I₂)cosδ) 的结果绝对差。
- 硅外延层厚度计算注意：硅折射率仍然不是常数（不同波长下略有不同），**结果约
  3.5 μm**，可用均值、标准差表示最终结果；按常数（n_Si = 3.42）计算"结果可能也
  不错，但没有达到题目的要求"；**希望学生仅使用附件数据反演出硅的折射率**（用类似
  介电常数公式或参数由硅数据拟合的 Cauchy 色散方程也可取）；若认为硅数据受多光束
  干涉影响，一定要使用减少多光束干涉影响的公式且**前后保持一致**；可以使用非线性
  最小二乘方法计算。碳化硅数据没有受到多光束干涉影响，其厚度值不必重新计算。

## 逐问加分点与扣分点摘录

加分（明确鼓励）：
- 厚度以均值 ± 标准差报告（多值汇总为统计量）；
- 算法全自动无人工干预、含平滑/滤波去噪、同晶圆一致性核验；
- 用两种完全不同的方法互证（可靠性证明）；用估计参数回算反射率与附件对比；
- 多光束必要条件给出定量指标并连到精度影响；回答与必要条件自洽且有理由；
- 仅用附件数据反演折射率（而非文献常数）。

扣分（明确不好的做法）：
- 使用常数折射率（n=2.55 / n_Si=3.42）即使结果接近也"没有达到题目要求"；
- 手工找波峰波谷（人工干预）；
- 把一致性当可靠性；
- 照搬"光干涉三条必要条件"（无用）；
- 对 reststrahl band 数据照算不误；
- 前后模型不一致（判定受多光束影响却不改进计算公式）。

## 关键数值（供答案基准交叉验证）

- 问题 2 外延层（碳化硅）厚度约 7.5 μm（均值 ± 标准差形式）。
- 问题 3 硅外延层厚度约 3.5 μm。
