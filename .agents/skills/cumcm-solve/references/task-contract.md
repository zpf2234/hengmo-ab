# 任务契约

读题和附件体检后，先写 `求解/任务契约.json`。它是求解、论文和审查三阶段共同使用的
机器可读边界，禁止在后续阶段静默改变。

```json
{
  "竞赛年份": 2025,
  "赛道": "B",
  "赛题标题": "碳化硅外延层厚度的确定",
  "参考答案在求解期可见": false,
  "题面来源": ["题目/B题.pdf"],
  "附件": [
    {"路径": "数据/附件1.xlsx", "角色": "输入", "单位": ["cm^-1", "%"]}
  ],
  "官方输出": [
    {"路径": "result1.xlsx", "格式": "xlsx", "模板必须保留": true}
  ],
  "问题": [
    {
      "编号": 1,
      "原型": ["机理", "逆问题"],
      "必答内容": ["厚度模型", "变量与单位", "适用条件"],
      "依赖": [],
      "候选路线": [
        {"名称": "色散相位联合拟合", "角色": "主候选", "关键假设": ["单层结构"], "淘汰条件": ["合成回收失败"]},
        {"名称": "极值级次回归", "角色": "异构挑战", "关键假设": ["极值级次可辨"], "淘汰条件": ["峰位不稳定"]}
      ],
      "答案证据要求": ["合成信号回收", "双角度一致性", "折射率误差传播"],
      "主验证": "合成信号参数回收",
      "补充验证": "量纲与极限情形",
      "fallback": "色散关系不足时报告光学厚度及折射率敏感区间",
      "失败条件": ["科学错误：厚度单位不一致", "交付错误：未说明折射率依赖"]
    }
  ]
}
```

## 规则

- `问题` 数量和编号必须与题面一致。
- `原型` 从机理、几何、统计、预测、评价、优化、仿真、决策、逆问题中选择，可多选。
- `必答内容` 写评委可直接核对的输出，不写“建立合理模型”等空目标。
- 每问指定一项主验证和一项不同机制的补充验证。
- 每问列出至少两条真实可执行的 `候选路线`，并写明角色、关键假设和淘汰条件。基本规律唯一时，
  可改写为非空 `唯一模型理由`，但仍须保留独立数值或估计路线挑战主实现。
- `答案证据要求` 至少包含两项，覆盖独立验证以及误差、可识别性、最优性或稳健性之一。
- 每问提供可执行 `fallback`，说明主模型失效后仍能保留哪些答案。
- `失败条件` 至少包含一个以“科学错误”标识的条件和一个以“交付错误”标识的条件。
- 所有附件标明输入、模板输出或参考资料；输出模板不得当作输入数据。
- 题意口径变化时先更新契约并记录原因，再重跑受影响问题；论文阶段不得直接改口径。
- 顶层记录 `参考答案在求解期可见: false`；冻结最终答案后才允许独立审查者进行隐藏答案比较。
