# CUMCM 统计计算契约

本规则用于数据、预测、试验、评价、抽样与统计决策类分问，保留原统计建模技能中会影响结果
正确性和复现性的部分，不保留独立技能触发。

## 1. 数据语义先于模型

编码前冻结个体键、时间键、分组键、场景键、单位、输出模板和随机预算。空白、N/A、0、负数
和特殊字符串逐类解释，不把所有“缺失”统一填补。

至少区分：

- observed：观测真实存在；
- eligible：对象属于当前比较集合；
- denominator：能进入均值、份额、排名等分母；
- sentinel：数值只是“不适用”的编码；
- outcome：已知状态或最终标签。

结构性不存在的对象不得进入分母。归一化、排名和份额计算后按组/时间检查加和、方向、样本数和
边界对象。

## 2. 数据形态

重复时段、来源、评分者、传感器或实验列优先转成长表/面板表；保留原始宽表用于核对。长表主键
必须唯一，并记录有效来源数、缺失来源数和分母集合大小。时间预测不得随机打乱未来，分组或
重复测量不得拆散到训练与测试两侧。

## 3. 最小充分建模顺序

1. 建立可解释基线：均值、比例、规则、线性/逻辑回归或确定性打分。
2. 用小算例和已知结果核对方向、量级、分母、约束与输出。
3. 只有基线在冻结指标上失败时，才加入非线性、混合效应、正则化、bootstrap、贝叶斯、
   Monte Carlo、树模型或其他复杂路线。
4. 复杂路线必须使用同一数据口径和留出规则，增益需超过抽样不确定性。

隐变量先由已知结果写成可行条件，再在正确支持集上估计；份额变量使用单纯形或等价约束。
机制比较应把各规则写成相同输入输出契约的函数，在同一对齐样本上运行。

## 4. 验证

按题型选择至少两类：

- 已知结果复现率或严格留出表现；
- 置信/可信区间、bootstrap 或样本量收敛；
- 决策边际、约束松弛量、区间宽度、熵或集中度；
- 时间外推、分组留出、异常/边界/高影响样本审计；
- 随机种子、先验、权重、阈值和抽样次数扰动；
- 组成数据加和、概率校准和残差结构。

不能通过改指标定义刷高结果。精确复现较差时如实报告，并回查分母集合、排名方向、结构性
不适用行和必要约束，再考虑调参。

## 5. 结果契约

模型结果与处理后数据分开保存。每列使用稳定名称、单位和含义，至少包含点估计、区间/标准差、
实际/预测状态、是否一致及关键边际。图表只读取已落盘结果，不依赖 notebook 隐藏状态；每张图
绑定一个结论、坐标单位和矢量输出。
